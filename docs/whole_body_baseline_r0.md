- 잰 날: 2026-09-27. 코드: `wbs-impl` R0 커밋 (물리는 `f32b5d1`·`1d49abb`와 같다. 아래 "같음 확인").
- 설계서: `docs/whole_body_strike.md` L0·15장. 이 문서는 뒤 라운드가 견줄 **버그 상태** 기준이다. R1(걸음 방향 버그 고침) 뒤에 다시 재서 새 기준을 따로 남긴다.

## 2. 지탱도 s (읽기만)

| 상황 | hybrid | levitate |
|---|---|---|
| 가만히 섬 (3~8초) | 평균 1.000, 최저 0.999 | 1.000 |
| 앞 약 0.9 m/s 걷기 | 평균 0.41 (0.36~0.46) | 1.43 m/s로 걷고 0.13 |
| 뒤·옆·비스듬히 (0.7~0.95 m/s) | 평균 0.39~0.51, 10~90% 구간 0.34~0.55 | 0.06~0.19 |
| 앞 끝까지 (2.2 m/s) | 0.23 | 0.06 |
| 제자리 베기 50번 | 평균 0.98, 최저 0.93 | |

- 설계 합격선 "서기 ≥ 0.98"은 넘는다. "걷는 동안 0.35~0.75 사이를 오간다"는 hybrid 10~90% 구간 0.34~0.55로 아래 끝이 0.01 모자라고 위로는 0.55까지만 간다. 걷는 동안 한 발 딛기(−0.25)와 속도 몫이 겹친 값이다. L4(R7)가 쓰기 전에 걷기 범위를 다시 본다.
- levitate는 딛음을 발 무게(`footLoad > 0.5`)로 가리는데, 걷는 동안 한 발도 0.5를 못 넘는 순간이 많아 s가 0 근처로 떨어진다. levitate에서 L4·L5를 쓸 때 딛음 판정을 다시 봐야 한다.
