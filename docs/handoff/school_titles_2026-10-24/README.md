- 얻은 호칭은 잃지 않는다. 유파 초기화 뒤에도, 방랑에서 진 뒤에도 남는다(사장님 확인 전).

- 호칭 하나마다 내 카드 뽑기의 레전드 확률이 +0.2 %p, 커먼이 −0.2 %p 이다(`TITLE.legendStep` — 여정 · 방랑만).
- '여행자'는 호칭이 아니다. 호칭이 없으면 레벨 옆에 흐린 '호칭 없음'이 보인다. 처음 얻은 호칭이 저절로 지금 호칭이 된다.

## 저장 (`stillness.lobby.progress.v1`)

- `titles: [{ event, name, seen }]` · `title`(호칭이 없으면 '')
  - 이름은 사건 열쇠로 표에서 다시 읽는다. 표 이름을 바꾸면 저장된 호칭과 고른 호칭도 새 이름으로 보인다.
- 얻는 조건은 저장할 때마다 맞춘다(`lobby_progress.js` `save` → `grantTitles`).
  - 그래서 칸을 산 저장, 방랑이 열린 저장, 이긴 판 저장에 호칭이 같이 들어간다.
  - 저장이 막히면 칸도 호칭도 남지 않는다.
- 대기실을 열 때 `checkTitles` 가 한 번 더 본다. 이미 조건을 채운 옛 저장에 호칭과 알림을 한 번 준다.
- `regicide: { run, foes }`: 이번 방랑(방랑 id)에서 이긴 왕이다. 방랑 칸 밖에 두었다(방랑 코드를 건드리지 않음).
- `earned: { coins, heads }`: 싸움 보상으로 번 것이다. 보상을 주는 그 저장에서 더한다.
  - 옛 저장은 처음 읽을 때 '지금 가진 것 + 칸에 낸 값'으로 셈해 다음 저장에 적는다.

## 알림 창

| 어디 | 언제 | 꼴 |
|---|---|---|
| 대기실(스킬 화면 위 포함) | 칸을 사서 얻음 · 대기실을 열 때 안 본 호칭 | `#titleDialog` — 스킬트리 알림 창과 같은 창 · 금색 '확인' |
| 싸움 결과 창 위 | 판 끝에 얻음(방랑자 · 왕 시해자 · 정복자 · 도살자 · 대부호 · 나무꾼) | `src/title_notice.js` — 방랑 알림 창과 같은 창 · 금색 '확인' · 방랑 알림 창이 떠 있으면 그 다음 |

- 글은 '호칭을 얻었습니다', 호칭 이름(금색), 까닭 한 줄이다.
  - 예: '독일 유파의 모든 기술을 익혀 캄프페히텐 계승자가 되었습니다.'
- 두 개 이상이면 얻은 차례로 한 창씩 띄운다.
