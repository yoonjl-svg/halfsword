## 1. 단추 = 싸움 화면 단추 (②)

### 1-1. 같은 값을 어떻게 — Shadow DOM 안에 싸움 꼴을 한 번 더

첫 화면 · 대기실은 `#gameEntrance` 의 Shadow DOM 안이라 싸움 화면 CSS(`index.html`)가 들어오지 않는다. 대신 `:root` 의 사용자 속성(`--c-accent` · `--line` · `--panel` · `--fs-m` …)은 물려받는다.
그래서 새 파일 **`src/entrance_ui.css`** 하나에 싸움 화면의 `.primary` · `.secondary` · `.toggle` 을 **같은 토큰 · 같은 값**으로 옮겨 적고, 첫 화면(`game_entry.js`)과 대기실(`lobby.js`)이 함께 넣는다.

| | 싸움 화면 (index.html) | 첫 화면 · 대기실 (entrance_ui.css) |
|---|---|---|
| 주 단추 | 바탕 `--c-accent` · 글 `--c-on-accent` · 14 · 700 · 테두리 없음 · 모서리 8 · 패딩 13 (높이 500 이하 10) | 같음 — `.primary` |
| 부 단추 | 바탕 없음 · 1 px `--line` · 글 `--c-text` · 14 · 400 · 모서리 8 · 패딩 11 (8) | 같음 — `.secondary` |
| 미닫이 | 44 × 24 · 모서리 12 · 1 px `--line` · 꺼짐 `rgba(0,0,0,.4)` · 켜짐 `--c-accent` · 손잡이 18 (2 → 22 px) | 같음 — `.toggle[aria-checked]` |

- 예전 `--line` 을 첫 화면 · 대기실이 다른 색(`#65513a` 나무 가름줄)으로 덮어쓰고 있었다 → 싸움 화면 `--line` 을 그대로 물려받게 하고, 공지 · 설정 · 계정 창의 가름줄만 `--dlg-line` 으로 이름을 바꿨다(창 꼴은 그대로 — §8 사장님께).
- 대기실은 더는 첫 화면의 `start_pixel.css`(나무 판자 꾸밈)를 넣지 않는다. 세로 폰에서 창을 감추는 줄(10/16 14:0x)은 둘이 함께 쓰는 `entrance_ui.css` 로 옮겼다.

### 1-2. 한 창에 주 단추 하나

| 화면 | 주 단추 | 부 단추 |
|---|---|---|
| 첫 화면 | 처음부터 | 이어하기 (누를 수 없을 땐 흐리게) |
| 공지 · 설정 | 확인 | — |
| 계정 | 인증번호 받기 · (번호 단계) 연결하기 | 닫기 |
| 대기실 | 여정 시작 / 여정 이어가기 | 첫 화면으로(작게) |
| 칸 설명 카드 | 장착 · 해제 가운데 **지금 누를 수 있는 것** | 다른 하나 = 누를 수 없는 부 단추 |
| 책 설명 카드 | 구입 · 사용 · 봉인 가운데 지금 누를 수 있는 것 | 다른 하나(사용 중이면 '사용', 봉인이면 '봉인') |
| 이름 창 | 저장 | 취소 |

- 장착 · 해제와 책 단추는 **누를 수 있나**로 꼴을 고른다(`:not(:disabled)` — 스킬북 단추 꼴은 다른 작업자 파일이라 자리로).
- 장착 · 해제는 칸을 고르면 뜨는 설명 카드 안으로 옮겼다 — 책 설명 카드(구입 · 사용 · 봉인)와 같은 자리 · 같은 꼴. 틀 밑 단추 줄이 없어진 만큼 재고 틀이 커졌다(§4).
- 탭(대기실 메뉴 넷 · 스킬북 유파 다섯) = 같은 꼴: 테두리만 · 고른 것 = 금색 테두리 + 금색 글 · 모서리 8 · 12 px(고른 탭 600).
- 작은 부 단추(첫 화면 아래 줄 공지사항 · 설정 · 계정 연결 · 대기실 '‹ 첫 화면으로') = 부 단추 꼴 · 글 12 · 높이 28. 아래 줄 세 칸은 전과 같은 70 px 폭.
- 그림(픽셀 숲) 위에 바로 놓인 부 단추(이어하기 · 아래 줄 · 첫 화면으로)는 싸움 창 바탕 `--panel` 을 깐다 — 싸움 화면의 부 단추 뒤에는 늘 창(`.card`)이 있어 같은 모습이 된다.

### 1-3. 덜 매끄러워 보이던 까닭 넷 (감독 진단) → 고친 것

| | 까닭 | 고친 것 |
|---|---|---|
| (a) | 나무 창(볼록 테두리 · 딱딱한 계단 그림자) 위에 놓임 | 대기실 창 = 싸움 창(§3). 첫 화면은 그림 위 — 부 단추에 창 바탕 |
| (b) | 누르면 3 px 뚝 떨어짐(`start_pixel.css :active { transform: translateY(3px) … }`) · 바탕 꾸밈의 1 px 내려앉기 | 둘 다 지움 — 싸움 단추처럼 눌러도 그 자리 (시험: 누른 채 위치 · transform 그대로) |
| (c) | 첫 화면 전체가 0.7 s **7 단계로 끊어** 나타남(`steps(7)`) | 끊어 나타나기는 픽셀 제목 글자(적막 · STILLNESS · 가름줄)에만 · 단추와 아래 줄은 같은 0.7 s 매끈하게(ease). 움직임 줄이기면 모두 바로 |
| (d) | 따로 적은 CSS 라 크기 · 굵기 · 모서리가 조금씩 달랐다 | 값은 `entrance_ui.css` 한 곳 — 싸움 화면 토큰 그대로 · 시험이 싸움 화면 계산값과 맞대 본다(아래) |

- 그 밖에 단추에서 뺀 픽셀 흔적: 나뭇결 무늬 그러데이션 · 볼록 테두리(위 · 왼쪽 밝게) · 잘라 낸 모서리(clip-path) · 글 그림자 · 단추 앞 픽셀 화살표 · 점선 초점 테두리(→ 금색 한 줄).

### 1-4. 싸움 화면과 맞대기 — 계산값 (`tools/browser/ui_unify_smoke.mjs` ①)

싸움 화면 = 게임 인자 주소의 메뉴 `#btnStart`(주) · 싸움 중 정지 창 `#btnResume`(부). 첫 화면 · 대기실 쪽 = 처음부터 · 공지 확인 · 설정 확인 · 인증번호 받기 · 여정 시작 · 장착 · 봉인 · 이름 저장(주) / 계정 닫기 · 이름 취소(부).
비교한 값 16 가지: 모서리 · 바탕색 · 글 색 · 글꼴 · 글 크기 · 굵기 · 위 테두리 두께 · 모양 · 색 · 패딩 넷 · 최소 높이 · 줄 높이 · 자간 — **모두 같음** + 높이도 같음.

| 크기 | | 싸움 화면 | 첫 화면 · 대기실 |
|---|---|---|---|
| 844 × 390 | 주 | 패딩 10px · 높이 36 · rgb(217, 164, 65) · 14px 700 · 모서리 8px · 테두리 0px | 처음부터 36 · 공지 확인 36 · 여정 시작 36 · 장착 36 — 패딩 10px · 같은 값 |
| | 부 | 패딩 8px · 높이 34 · 바탕 없음 · 1 px `--line` · 14px 400 · 모서리 8px | 계정 닫기 34 · 이름 취소 34 · 이어하기 34(바탕 rgba(24, 18, 14, 0.88)) — 같은 값 |
| 1280 × 720 | 주 | 패딩 13px · 높이 42 · rgb(217, 164, 65) · 14px 700 · 모서리 8px · 테두리 0px | 처음부터 42 · 공지 확인 42 · 여정 시작 42 · 장착 42 — 패딩 13px · 같은 값 |
| | 부 | 패딩 11px · 높이 40 · 바탕 없음 · 1 px `--line` · 14px 400 · 모서리 8px | 계정 닫기 40 · 이름 취소 40 · 이어하기 40(바탕 rgba(24, 18, 14, 0.88)) — 같은 값 |

자리 때문에 다른 것 (시험이 따로 확인):
- **폭**: 싸움 창 단추는 창 폭(약 300 px). 첫 화면 228 (낮은 화면 205 — 전 나무 판자 폭 그대로) · 공지 · 설정 확인 72 · 장착 · 해제 최소 72 · 출발 = 카드 폭.
- **이어하기 · 아래 줄 · 첫 화면으로**: 바탕 = 싸움 창 `.card` 바탕(`rgba(24, 18, 14, 0.88)`) — 그림 위라서(1-2).
- **작은 부 단추**: 글 12 · 패딩 6 12(아래 줄은 70 px 칸이라 옆 0) — 나머지 값은 부 단추와 같음.
- **누를 수 없는 단추**: 싸움 화면엔 이런 단추가 없다 → 부 단추 꼴을 흐리게(.4 — 감독 시안 값).
- 두 단추를 옆에 둘 때(장착 · 해제 · 이름 저장 · 취소)는 가운데 맞춤 — 줄 높이로 늘이면 부 단추(34)가 주 단추(36) 높이로 늘어나 싸움 값과 달라진다.

## 2. 미닫이 (③)

- **'화면 60 fps 제한'**(첫 화면 설정): 네모 체크 → 싸움 화면 미닫이. `<button role="switch" aria-checked>` · 글(`<label for>`)을 눌러도 켜고 끈다 · 누르면 바로 저장(같은 `gladiator-settings` fpsCap · 싸움 메뉴의 미닫이도 같이 바뀜 — 전 체크 상자의 change 와 같은 때) · 저장 못 하면 되돌림.
- **'지난 업데이트 숨김'**(공지): 같은 미닫이 · 저장은 전처럼 '확인'을 누를 때.
- 시험: 꼴(44 × 24 · 모서리 12 · 손잡이 18 · 2 → 22 px · 켜짐 금색) = 싸움 화면 `.toggle` 계산값 · 화면 읽기 이름(aria-labelledby) · 글 누름 · 저장(ui_unify_smoke ③ · game_entry_smoke · title_smoke — Playwright 의 check/uncheck 가 role=switch 를 그대로 다룬다).

## 3. 색 수 (④)

### 3-1. 검토 — 첫 화면 그림 때문에 색이 많은가

- **맞다 — 감독 확인 그대로**: 대기실 배경 숲은 첫 화면과 **같은 그림 코드**(`src/pixel_grove.js` — `createPixelGrove` 를 첫 화면 `start_screen.js` · 대기실 `lobby.js` 둘 다 부름)이고, 그 팔레트는 CSS 와 따로 된 **58 색**(코드의 색 59 가운데 `#fff` 하나는 '대기실' 글자를 그리는 틀).
- 그래서 UI(CSS) 색만 줄이면 배경은 그대로 — 배경 · 큰 글자 · 사슬 틀은 '겉(픽셀)'이라 UI 색 수에 세지 않는다(스타일 규칙 §5-3). 배경 팔레트를 줄이면 그림이 달라지므로 손대지 않았다.

### 3-2. 대기실 UI 색 — 전 59 → 후 17

세는 법: 대기실(무기 · 방어구 · 스킬북(산 책 · 안 산 책) · 상점 · 이름 창 · 호칭 상자)을 열어 **화면에 그려진 요소의 계산값**(글 · 바탕 · 그러데이션 · 테두리 · 그림자 · SVG 칠 · ::before/::after · 창 바탕 막)을 모은다. 그림(숲 · 캐릭터 · 글자 캔버스 · 아이템 그림 · 금화/주머니/책 그림 · 사슬 틀 · 카드 바탕 무늬 · 배경 어둡게 막)은 뺀다. `tools/browser/uiunify_capture.mjs`.

| 후의 색 | 무엇 |
|---|---|

## 4. 사슬 틀 · 세 칸 (⑤)

- **세 칸이 위 · 아래 줄을 같이 쓴다**: (캐릭터 카드 + 출발 단추) | 내 정보 | 재고 · 상점 · 스킬북. 카드 위 = 칸 위, 출발 단추 아래 = 칸 아래. 내 정보 칸의 메뉴 탭 넷은 칸 아래에 붙였다(아래 줄이 맞게).
  - 크기는 칸 높이 하나(`--col-h`)에서 모두 셈 — 카드 높이 = 칸 높이 − 출발 단추 − 틈, 재고 틀 = 칸 높이 − 창 제목 · 여백. 큰 화면(PC)은 칸 높이를 520 px 까지 두고 위아래 가운데.
  - 알림 줄(인장 → 금화 · 이름 저장 · 출발 실패)은 출발 단추 밑에서 **제목 줄 가운데 작은 창**(한 줄)으로 옮겼다 — 아래 줄을 밀지 않게(카드 위에 띄워 보니 캐릭터 머리를 가려 제목 줄로).
- **틀 두께 셋 다 14 px** = 틀 그림 한 칸 2 px. 전에는 높이가 낮은 화면에서 12 px(한 칸 1.71 px — 칸이 고르지 않았다). 작은 폰도 같게 둔다 — 7 px(한 칸 1 px)는 사슬 무늬가 너무 잘아 안 읽힌다(사장님 확인 전).
- **틀 길이 = 사슬 한 마디(12 px)의 배수** — 모서리 옆에서 마디가 잘리지 않는다(CSS `round()` · 못 쓰는 브라우저는 반올림 없이).

- **재고 틀 = 별자리 틀**(같은 바깥 크기 · 같은 자리): 별자리 틀이 유파 탭 + 판을 함께 품는다. 탭을 바꿔도 틀이 움직이지 않는다. 판은 별자리 비 300 : 210 그대로 — 탭 아래 남은 자리에 들어가는 가장 큰 판을 가운데에 둔다(책 자리가 % 라 비가 바뀌면 680 × 360 에서 판 끝 책 이름이 밖으로 나갔다 · 남는 곳은 같은 바탕이라 띠로 안 보임). 판: 844 → 293 × 205 · 740 → 259 × 181 · 680 → 224 × 157 · PC → 516 × 361. 폭 680~779 는 내 정보 칸 최소 폭 150 px(판이 너무 작아지지 않게).

## 5. 호칭 내림 상자 · 대표 유파 (⑥ · 16:0x)

- 내 정보 첫 줄 = **'Lv.N'**(글 그대로 · 본문 색 · 굵게 — 전 금색) + **호칭 단추**(싸움 부 단추 꼴: 본문 색 글 + 작은 갈매기표 · 1 px `--line` · 모서리 8 · 금색 아님).
- 누르면 단추 **바로 아래로** 작은 창이 열린다: 싸움 창 꼴 `--panel`(**반투명** — 뒤 대기실이 조금 비친다 · 불투명하게 덮지 않음) · 1 px `--line` · 모서리 10.
- 창에는 **가진 호칭만** — 지금은 기본 호칭 '여행자' 하나(지금 호칭 = 굵게 + 금색 ✓). 나중에 얻은 호칭이 같은 목록에 붙는다. **'(호칭 없음)' 같은 시스템 알림 · 빈 줄 글은 없다**(사장님 16:0x — 처음 지시의 '(호칭 없음)' 줄은 만들지 않음).
- 고르면 `stillness.lobby.progress.v1` 의 `title` 에 저장 — 새로 고쳐도 그대로.
- 화면 읽기 · 키보드: 단추 `aria-haspopup="listbox"` · `aria-expanded` · 목록 `role=listbox` · 줄 `role=option` · `aria-selected`. 단추에서 ↓ ↑ = 열기(지금 호칭에 초점) · 목록에서 ↑ ↓ Home End = 옮기기 · Enter Space = 고르기 · Esc = 닫고 단추로 · Tab = 닫기 · 바깥을 누르면 닫힘.
- 자료 API (`src/lobby_progress.js` — 호칭을 지어 넣지 않음): `DEFAULT_TITLE = '여행자'` · `titleOptions()`(기본 먼저 + 얻은 차례 · 같은 이름 하나) · `selectTitle(name)`(가진 호칭만 · 돌려줌 { ok, saved }) · 얻기 = 이미 있던 `unlockEventTitle(event, name)`(사건마다 한 번 · '여행자'는 거름). 단위 시험 `tools/sim/lobby_progress.test.mjs`.
- **대표 유파 칸 없음** — 칸 · 셈(`representative`)을 지웠다.

## 6. 대기실 칸 그림 (⑨ 1 단계 — 감독 검토 §2)

- **매끈하게**: `.inventory-item img` · `.coin-icon` 의 `image-rendering: pixelated` 를 뺐다(금화 · 주머니 그림은 다른 작업자가 매끈한 그림으로 바꾸는 중).
- **보이는 그림 = 칸의 약 80 %**: 그림 파일의 투명한 가장자리를 빼고 잰 뒤(64 칸 · 알파 > 24 — `lobby.js fitThumb`) 보이는 부분의 긴 쪽이 칸 안쪽의 80 % 가 되게 키우고 가운데에 둔다. 케틀 햇은 그림 파일 안에서 폭 65 % 뿐이라 상자만 80 % 로는 칸의 약 52 % 였다(전 49 %).
  - 잰 값(칸 바깥 폭 대비): 나뭇가지 0.67 → 0.77 · 케틀 햇 0.491 → 0.752 (844 × 390).
- **등급 빛**: 칸 뒤에 무기 카드 앞면(`.wthumb`)과 같은 원 빛 `radial-gradient(closest-side, <등급 빛>, transparent)` · 같은 그림자 — 케틀 햇 = 레전드 금빛 `rgba(255, 210, 74, .6)` · 나뭇가지 = 쓰레기 회색 `rgba(190, 188, 180, .2)`(index.html `--tg` 값 그대로).
- **'장착 중'**: 칸 아래를 덮던 띠 → 칸 **왼쪽 위 귀퉁이에 걸친 작은 알약**(10 px · 600 · 금색 바탕 · 글 그대로). 무기 그림은 모두 ↗ 대각선이고 케틀 햇은 위가 비어 그 자리가 빈다 — 시험이 알약 아래의 그림 화소가 0 인지 센다.
- 칸 = 싸움 창 꼴(1 px `--line` · 모서리 6 · 고른 칸 금색 테두리). 설명 카드 바탕은 `--panel` 두 겹(거의 불투명 — 칸 · 별자리가 글 뒤로 비치면 읽기 어려워서. 반투명 창은 호칭 상자).
- 만들지 않은 것: 칸을 누르면 뜨는 큰 카드 앞면 설명(감독 제안 — 사장님이 고르지 않음).
