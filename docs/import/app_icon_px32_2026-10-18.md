## 3. 홈 화면 이름 'Stillness'

- 게임 주소의 HTML 제목 · `apple-mobile-web-app-title` · 매니페스트 `name` / `short_name` 은 이미 모두 'Stillness'(10/17 바뀜 — 지금 배포판에서도 확인). 그런데 폰에서 홈 화면에 추가하면 옛 이름이 떴다.
- 까닭(추정): 서비스 워커가 HTML 은 네트워크 먼저지만 **매니페스트는 캐시 먼저**였다. 매니페스트는 주소가 늘 같아(`manifest.webmanifest`), 폰에 깔린 옛 판 워커 캐시의 옛 매니페스트(옛 이름)가 계속 나갔다. 새 판 워커가 깔리려면 목록 전부(약 9 MB)를 받아 해시까지 맞아야 해서, 그 사이(또는 설치가 자꾸 어긋나면 계속) 옛 매니페스트가 남는다.
- 고침:
  1. 매니페스트 **새 이름** `stillness-20261018.webmanifest` 를 `index.html` 이 건다(HTML 은 네트워크 먼저라 바로 닿고, 새 이름은 옛 캐시에 없어 네트워크로 받음). `id` · `start_url` · `scope` 는 같은 폴더 기준 './' 그대로라 같은 앱. 옛 `manifest.webmanifest` 도 같은 내용으로 둠.
  2. 서비스 워커 틀(`tools/pwa/sw-template.js`): 매니페스트도 HTML 처럼 **네트워크 먼저**(오프라인이면 깔린 판의 것).
  3. `tools/pwa/build.mjs` 필수 목록에 새 이름 7 개 · `tools/pwa/lifecycle.mjs` 매니페스트 주소 확인을 새 이름으로.
- 이미 홈 화면에 옛 이름으로 만든 아이콘은 이름이 저절로 안 바뀐다 — 지우고 다시 추가. 그래도 옛 이름이면 주소 끝에 `?nosw=1` 을 붙여 한 번 열면(이 게임의 캐시 · 워커를 지움) 그다음 추가부터 새 이름.
