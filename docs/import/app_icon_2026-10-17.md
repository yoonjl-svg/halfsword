## 2. 우리 쪽에서 바꾼 곳

- `public/icons/`: 같은 이름 8 개를 새 그림으로 덮고, 새 이름 6 개를 더함. 옛 이름도 남겨 새 그림으로 덮었으므로 옛 HTML · 옛 매니페스트를 쥔 곳이 옛 주소로 다시 받아도 새 그림이 온다.
- `index.html` `<head>`: 탭 아이콘 32 · 64 와 `apple-touch-icon` 이 새 이름을 건다. `apple-touch-icon` 의 `sizes` 는 `192x192` → `180x180`(파일 실제 크기). 매니페스트 링크 주소 `./manifest.webmanifest` 는 그대로.
- `public/manifest.webmanifest`: 아이콘 셋(any 192 · any 512 · maskable 512)이 새 이름을 건다. `sizes` · `purpose` 는 그대로.
- `tools/pwa/build.mjs` `REQUIRED`: 새 이름 6 개를 더함(옛 이름 5 개는 그대로 — 파일이 남아 있다).
- `tools/pwa/lifecycle.mjs`: `apple-touch-icon` 폭 확인 192 → 180.
- `px32.png` · `px32_mask.png`: 읽는 코드는 없다. `tools/icon/gen_app_icon.py` 가 옛 도트 그림을 뽑을 때 써내는 이름이고, `docs/pwa_2026-10-13.md` 에 '원본'으로 적혀 있었다. 이제 둘 다 `favicon-32.png` 와 같은 바이트다(샛별 `61b257e5` 그대로 — `px32_mask` 는 더는 마스크가 아니다).
- **`tools/icon/gen_app_icon.py` 는 옛 도트 그림을 뽑는다** — 다시 돌려 `public/icons/` 에 쓰면 새 그림이 옛 그림으로 덮인다.
- maskable 은 any 512 와 같은 바이트(가장자리까지 그린 그림)다. 안드로이드 런처가 모양대로 자르면 안전 원(가운데 지름 80 %) 밖인 달 일부 · 나뭇잎 가장자리가 잘릴 수 있다. 검은 원 안이다.

## 4. 설치된 앱 · 브라우저에서 아이콘이 바뀌는 조건

- 브라우저 탭: HTML 은 네트워크 먼저(`tools/pwa/sw-template.js`)라 새 판을 연 다음부터 새 이름 탭 아이콘을 건다. 옛 이름 캐시와 상관없다.
- 아이폰 홈 화면(Safari '홈 화면에 추가'): 아이콘은 추가할 때 `apple-touch-icon` 을 받아 저장한다. 이미 추가한 아이콘은 새 판을 올려도 바뀌지 않을 수 있다 — 홈 화면에서 지우고 다시 추가하면 새 그림이다.
- 안드로이드 Chrome 으로 설치한 앱: Chrome 이 설치된 앱을 열 때 매니페스트를 다시 보고(하루에 한 번 꼴), 아이콘이 바뀌었으면 설치된 앱을 새로 만든다. 하루 넘게 걸릴 수 있고, 아이콘 · 이름이 바뀔 때는 사용자에게 확인 창이 뜰 수 있다. 바로 보려면 앱을 지우고 다시 설치한다.
- 데스크톱 Chrome · Edge 로 설치한 앱: 앱을 열 때 매니페스트를 다시 보고 아이콘을 바꾼다(확인 창이 뜰 수 있음).
- 이 상자의 크로미움 시험으로는 실제 홈 화면 · 안드로이드 설치 앱의 아이콘 바뀜을 확인할 수 없다 — 기기에서 확인.
