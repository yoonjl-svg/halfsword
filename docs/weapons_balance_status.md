   - **팔쉬온**: 반달칼 모양은 콜라이더와 ~1cm 안이라 유지, metalness 0.9 → 강철 표준 0.35 (같은 검은 막대 문제)
   - **모노호시자오(에픽)**: 외날 곡날 + 철 츠바·금 테두리, 금빛 하바키, 츠카이토(검은 비단 끈)와 흰 사메 마름모, 카시라
   - **츠바이핸더(레어)**: 파리어하켄이 z축(카메라 쪽)으로 뻗어 칼날 면 시점에서 안 보이던 것을 코등이 평면으로 고침,
     리카소 가죽 감개·풀러(피홈) 추가 — 레어 마감이 한눈에 읽힌다
   - 레이피어(레어)는 컵 힐트·스웹트 가드로 이미 충분히 읽혀 그대로
   - fighter.js: 두 외형 경로 공존(partMesh 곡날 + 색 null 숨김/decorate 칼날), 등급 마감(tierFinish) 양쪽 적용, decorate 칼날에도 피 밑색 갱신
3. **밸런스 — 13종 전부 목표 안** (docs/weapons.md §4d)
   - 근본 원인: **cutTime 보정 누락**. 측정 도구가 거리만 보정하고 cutTime은 raw(롱소드 0.43)로 적어, 배터리에선 롱소드 외
     모든 무기 AI가 "내 베기가 40% 늦다"고 착각했고, 실제 게임은 반대로 모든 무기가 롱소드 cutTime 0.3 그대로였다.
     둘 다 `0.3 × (무기 raw ÷ 롱소드 raw)`로 통일
   - 모노호시자오 질량 재분배(칼날 0.85 → 0.72kg, 총중량 유지): 칼끝이 무거워 휘두름이 머리 높이에 못 미쳐 실측 1.09가
     나오던 것(연구 세션 표 1.51과 불일치)이 1.58로 정상화
