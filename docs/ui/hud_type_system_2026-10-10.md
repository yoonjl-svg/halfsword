### 2.6 지금 모습 캡처 (`docs/ui/`)
`hud_before_{portrait,landscape}_` + `menu`(처음 메뉴) · `draw`(카드 뒷면 + 소개) · `cards`(앞면: 레전드·에픽·레어) · `start`(Battle·안내·소개) · `fight`(자세·상대 패시브·감정) · `foe_secret` · `cue_secretReady` · `cue_secretArm` · `cue_stiff` · `result`(패배 + 승리 대사) · `pause` · `result_card` · `overlap` (+ 세로 `rotate`).
실제로 띄운 것과 DOM 에 직접 넣은 것은 `tools/ui/hud_shots.mjs` 의 장면 메모에 적었다: **실제** — 메뉴·카드·Battle/안내/소개·상대 패시브·상대 비기(`enemy.techCue` 경로)·일시정지·#rotate. **직접 넣음** — 자세 이름 글(실제 자세표 글을 넣음), 감정 줄, 내 비기 창·고노센 준비·경직, 패배 글·승리 대사, 결과 창 글, 겹침 장면의 감정·기술·자세. 배경은 포세이돈 신전(밝은 하늘·모래 — 가장 나쁜 경우)과 개울가(어두운 숲).
세로 캡처는 터치 세로에서 실제로 덮는 '폰을 가로로 돌려주세요'만 숨기고 찍었다 (폰에서는 세로로 싸울 수 없다 — 세로는 PC 좁은 창·태블릿 대비).

### 나 · 상대 구분 (R2 · R3 · C)
- **자리로 먼저 나눈다**: R2(패시브·고유 동작)는 상대 것뿐이다(플레이어에게는 AI 가 없다). R3 는 둘 다.
- **꼬리표 첫 낱말로 나눈다**: `상대 · 독일 · 비기` / `나 · 독일 · 비기` 꼴 (낱말은 편집자 결정 — '나/내' 등). 꼬리표 서식은 R1 의 설명 줄과 같다.
- **색으로는 나누지 않는다** (사장님 '색만 다르게'는 칸 사이 구분 — 자세는 지금 색, 기술 칸은 오렌지). 같은 칸 안에서 나·상대를 색으로 또 나누면 색 수가 늘어난다.
- 내 비기 **창이 열림**(secretReady — 지금 눌러야 하는 조작 신호)은 R3 에 이름을 띄우고 꼬리표를 `나 · 비기 · 지금` 꼴로, 칸을 0.6 s 간격으로 한 번 밝게(투명도 .7→1) 한다. 진동은 그대로. (지금은 가운데 크게 흐리게 — 사장님 '테스트 중엔 크게' 결정이 있어 §11 에 묻는다)
- 고노센 준비(secretArm)는 R3 에 흐리게(.6) — '준비된 상태'라 신호가 아니다.
- 경직(stiff)은 비기의 일부지만 **반응할 순간**이라 가운데 C 로 뺀다: 상대 경직 = 지금 칠 기회, 내 경직 = 지금 못 움직임. 글 `상대 경직` / `경직` (편집자 결정).

## 5. 글자 체계

### 글꼴
- **웹폰트를 들이지 않는다.** `--font-ui: system-ui, -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', 'Malgun Gothic', sans-serif` (지금 묶음 + 윈도의 맑은 고딕).
- 근거: ① 한글 웹폰트는 글자 수가 많아 Google Fonts 도 수십 조각으로 나눠 받는다 — 첫 판에서 글자가 늦게 바뀌는 깜빡임(FOUT)이 HUD 에서 그대로 보인다. ② 폰 게임이라 첫 실행·끊긴 망에서도 같아야 한다. ③ iOS(Apple SD Gothic Neo)·안드로이드(Noto Sans CJK = 본고딕)는 이미 좋은 고딕이고 800 굵기도 있다.
- 예외 후보(사장님 취향): 판 알림(D) 'Battle·승리·패배' 와 창 제목만 Google Fonts 의 명조·붓 계열(예: Gowun Batang · Nanum Myeongjo — 글자 몇 개라 `&text=` 로 그 글자만 받으면 수 KB) — §11.

### 외곽선·그림자 표준 하나
```
--outline-c: #0d0907;
--hud-outline: 1px 0 0 var(--outline-c), -1px 0 0 var(--outline-c), 0 1px 0 var(--outline-c), 0 -1px 0 var(--outline-c),
               0 1px 3px rgba(13,9,7,.85), 0 0 8px rgba(13,9,7,.5);
--hud-outline-display: 0 2px 0 var(--outline-c), 0 0 2px var(--outline-c), 0 3px 10px rgba(13,9,7,.7);   /* D 만 (큰 글자) */
```
- 네 방향 1px 짙은 갈색 테두리 + 부드러운 그늘. 밝은 하늘·모래 위에서도 글자 윤곽이 선다 (지금은 흐린 그림자 하나라 하늘 위 크림색이 번진다).
- 안내(H)는 알약 바탕(rgba(13,9,7,.5))이 있으니 외곽선 없음. 창·카드 안 글자도 외곽선 없음 (바탕이 짙다).
- 순수 검정(#000) 대신 짙은 갈색 — 화면의 따뜻한 결을 지킨다.

## 10. 구현 노트 (코드는 쓰지 않음 — 순서대로)

1. **index.html `:root`** — §5·§6 토큰 추가 (`--fs-*`, `--hud-outline*`, `--hud-*`, `--emo-*`, `--tier-*`, `--safe-*`, `--side-w`). 기존 `--ink` 등은 그대로. `[data-tier]` 의 `--tc` 는 `--tier-*` 를 가리키게.
2. **index.html 본문** — `#guardName` 을 오른쪽 위 묶음 `#rstack` 안 첫 칸으로, 그 아래 `#techSlot`(R2) · `#secretSlot`(R3) 새로 (각각 `<b>`+`<small>`, `aria-live="polite"`). `#techCue` 는 상태 칸(C)으로 남긴다(이름 `#stateCue` 로 바꾸거나 그대로). `#foeIntro` 는 자리만 왼쪽 위로.

4. **main.js `updateTechCue` / `showTechCue` / `showPlayerCue`** (1491–1570) — 칸 하나를 셋으로: kind → 칸 (`passive·unique·all → R2`, `secret·secretReady·secretArm → R3`, `stiff → C`). 칸마다 타이머 따로(`slotTimer.r2/r3/c`). holdSecret·holdMine·busy 를 없애고 R3 의 '내 것 우선 + 줄 1' 과 C 의 '상대 우선' 만. 설정 '유파 기술 알림'(techCue)은 R2·R3 의 상대 것만 끈다(내 비기는 조작이라 그대로 — 지금과 같다).
5. **main.js `updateGuardName`** (1458) — 바뀔 것 없음 (DOM 자리만 바뀐다). 설명 두 줄 자름은 CSS.
6. **main.js `showToast` · `showEmoMsg` · `showHint` · `showFoeIntro` · `showFoeLine`** — setTimeout 을 게임 루프 타이머로 (일시정지와 같이 멈추게). `showEmoMsg` 에 줄 세우기(최대 2). 센서·영점 알림은 `showHint` → `showEmoMsg`(알림 갈래, 감정 색 없이 `--hud-sys`).
