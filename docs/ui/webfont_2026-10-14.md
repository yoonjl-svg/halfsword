- **보충 둘**: 프리텐다드 서브셋에 없는 글자 47 자(한자 43 · ▮▯ — 이 셋은 통째에도 없음 · Ⅰ · ↻ — Ⅱ 는 일시정지 단추라 브라우저 기본 글꼴)를 구글 폰트의 `text=` 기능이 그 글자만 담아 준 파일로 채웠다. 한자는 프리텐다드 한글의 바탕인 본고딕(Source Han Sans)과 같은 집안인 Noto Sans **TC**(번체 — Noto Sans KR 에는 '掣' 가 없음), 기호 셋은 Noto Sans Math. 한 굵기 파일이라 `font-weight: 100 900` 으로 적어 굵은 자리에서도 흉내 굵기를 만들지 않는다. 새 한자·기호가 화면 글에 들어오면 `font_glyphs.mjs` 가 잡고, 다시 받는 법은 `public/fonts/README.md`.

- 방법: 화면 글(표기 방침 검사기와 같은 모음 `tools/text/texts.mjs` collectTexts — 유파·자세표·기술·무기·인물·main.js 글·index.html 글 + 무대 줄 + main.js 의 한글 없는 기호 글(▮▯) + test.html · test_pick.js · test_route.js 글)을 **index.html 의 @font-face 를 읽어** 글꼴 줄(`--font-ui`) 차례대로 대조한다 — 그 글꼴의 `unicode-range` 안이고 파일 글자표(cmap)에 있으면 그 글꼴로 그려진다(범위 안인데 없으면 브라우저처럼 다음 글꼴로). 한 글꼴의 굵기 파일이 여럿이면 모두에 있어야 그 글꼴로 친다. ## 4. 글자 규칙 (요약 — 자세히는 `hud_type_system_2026-10-10.md` §16)

- 크기 세 단계 작게 12 · 보통 14 · 크게 17 px + 큰 글자 예외 둘(판 알림 · 제목). 같은 px 에서 프리텐다드 한글이 갈무리보다 약 5 % 낮고 14 % 좁아(글꼴 파일에서 잼) 작게 12 는 사장님이 정한 카드 설명·왼쪽 위 크기(11 → 12)의 보이는 크기를 지키고, 보통·크게는 전 15·20 보다 11 %·19 % 작다.
- 카드: 이름 보통 · 설명 작게, 큰 카드(PC)는 이름·설명만 한 단계 위. 설명 줄이기(`fitCardText`)는 걷었다(시작 크기 = 가장 작은 단계).
- 굵기: 한 단계만 얇게 → 400 · 600 · 700. `font-synthesis: none`.
- 색: 넷 + 등급 색 예외. ② 기술 칸의 옅은 오렌지는 걷고(① 과 같은 본문·보조), 비기 창 열림만 강조 색.
- JS 가 크기를 정하던 곳: `layoutDraw` 의 `--name`·`--desc` px(20/15 · 15/12)와 `fitCardText` 를 걷어 내고 큰 카드 표(`#draw.wide`)만 단다 — 크기는 모두 CSS 토큰. `test_route.js` 의 테스트 경로 한 줄도 `var(--fs-s)` · `var(--c-sub)`.

## 5. 미리 받기 · 오프라인 앱 (PWA)

- 미리 받기(`<link rel="preload">`): 메뉴 첫 화면에 쓰는 셋 — 프리텐다드 400(부제·설정 줄) · 700('싸움 시작') · Cinzel 라틴('Stillness' · 'FPS') = **563,784 B** (전 갈무리 둘 + Jacquard = 689,808 B). 600(카드 고르기 안내·알약·감정 줄)은 카드 화면에서 받는다(메뉴에 없는 굵기를 미리 받으면 '안 쓰인 미리 받기' 경고). test.html 은 첫 줄에 쓰는 프리텐다드 셋. 모두 `font-display: swap`, 글꼴이 늦게 오면 카드 넘침을 다시 잰다(`document.fonts` loadingdone → layoutDraw — 그대로).
- `npm run build` → `pwa-build.json`: **315 → 320 파일** (글꼴 폴더 8 → 13 — 글꼴 넷·OFL 둘을 빼고 글꼴 일곱·OFL 넷을 더함) · **6,376,545 → 6,547,969 B** (+171,424 B — 글꼴 폴더 719,313 → 888,415, 한도 30 MB 안).
- 빌드한 HTML 의 글꼴 주소는 상대 주소(`./fonts/…` · `url(fonts/…)`)로 바뀌어 GitHub Pages 하위 경로에서도 맞는다(갈무리 때와 같은 방식 — `/fonts/…` 로 적음).

폰 가로 844×390(dpr 3, 터치) · PC 1280×720(dpr 1) · 세로 폰 390×844(돌려 달라는 안내)에서 메뉴 · 카드 고르기(뒷면 · 세 장 뒤집음) · 판 시작 소개 · 싸움(① · ② · 감정 줄) · ② 비기 창 열림 · 일시정지 · 결과 · test.html. 무대·상대·카드 고정(`?stage=poseidon&foe=heinrich&cards=longsword,pistol`). 127.0.0.1 밖으로 가는 요청은 막고 셌다. 화면마다 글자가 든 요소를 **모두** 훑어 계산된 크기·굵기·줄 높이·자간·색과 실제로 그린 글꼴(크로미움 `CSS.getPlatformFontsForNode`)을 적는다.
