- **뒤 라운드는 모두 이 문서와 견준다.** R0 문서(`whole_body_baseline_r0.md`)는 버그 상태 기준으로 남긴다.

## 4. AI 기술 걸음 (`wholebody.mjs aistep 8`, AI 대 AI 8판)

밀림은 닿은 뒤 0.5초 안, 그 발이 딛고 있는 동안 발바닥 가운데(뒤꿈치를 들면 발끝)가 닿은 자리에서 멀어진 거리다(`gait.js pinFeet`이 붙잡는 점). "실린 동안"은 G2와 같은 잣대로 그 발에 몸무게 0.1 W 넘게 실린 동안만 잰다.

| 항목 | 끔 (지나 딛기 0.6 m) | 켬 (앞발 내딛기 0.25 m, 0.3초) |
|---|---|---|
| 받은 부탁 / 휘두르기 (부른 횟수) | 92 / 156 (188) | 100 / 156 (204) |
| 기술 걸음으로 딛음 | 78/92 | 81/100 |
| 발 이동 가운데 (10~90%) | 0.35 m (0.04~0.77) | 0.24 m (0.16~0.38) |
| 닿을 때 몸 전진 가운데 (10~90%) | 0.04 m (−0.15~0.35) | 0.09 m (−0.04~0.23) |
| 부탁 → 닿기 가운데 | 0.60초 | 0.51초 (걷던 발이 먼저 딛은 뒤 시작) |
| 밀림, 실린 동안: 3 cm 넘음 / p99 / 최대 | 7.7% / 9.2 / 11.4 cm | **1.2% / 2.7 / 5.3 cm** |
| 밀림, 전체(가볍게 닿은 동안 포함): 3 cm 넘음 / p99 | 38.5% / 20.5 cm | 55.6% / 17.3 cm |
| 같은 싸움의 보통 걷기 걸음: 3 cm 넘음 전체 / 실린 동안 | 2.6% / 0.5% | 5.2% / 0.7% |
| 다시 딛기 (같은 발을 붙잡기·자세 고치기로 곧 다시 딛음) | 7.7% | **18.5%** |
| 부탁 뒤 1.5초 안 넘어짐 | 5.4% | 4.0% |
| 칠 때 몸 전진 가운데 / 상처 순간 상대 쪽 빠르기 (`ai 8`) | 0.06 m / −0.05 m/s | 0.05 m / −0.01 m/s |
| 준비 있는 내려베기 / 첫 신호 → 닿기 (`ai 8`) | 54.9% / 708 ms | 47.7% / 658 ms |

- 다시 딛는 걸음은 모두 같은 모양이다. AI의 `stepT`(최대 0.3초)가 끝나면 AI가 조이스틱을 뒤로 당기는데(`ai.js moveFeet`, −0.21 / −0.5), 앞발 내딛기는 걷던 발이 먼저 딛은 뒤에야 시작해서(부탁 → 닿기 0.5~0.7초) 발이 닿을 때 몸은 이미 물러나고 있다. 내딛은 발에 무게가 한 번도 0.1 W 넘게 실리지 않고, 0.45초쯤 뒤 떠 있는 발로 읽혀 같은 발로 다시 딛는다. 설계서 1-1의 시험(서 있는 플레이어, 부탁 한 번)에는 이 뒤로 당기기가 없어서 다시 딛기가 0이었다.
- 뒤로 당기기를 없애는 것은 L8(R6)의 일이다. R1 안에서 두 가지를 시험하고 되돌렸다: (A) 부탁한 걸음이 딛을 때까지 계속 내딛기(`fwd = 1`) → 다시 딛기 14.7%, 발 이동 가운데 0.41 m(90% 1.0 m, 걷기와 섞임), 휘두르기 수 +40%로 싸움이 바뀜. (C) 딛을 때까지 조이스틱 0 → 다시 딛기 9.1%, 실린 동안 밀림 3 cm 넘음 4.5%(더 나빠짐).

## 7. 성능 (`SWITCH=GAIT.fwdFix perf_ab.mjs 10 2000`)

- 스텝 시간 비 켬/끔 평균 0.93 (95% 구간 0.84~1.02).
- THREE 생성/스텝이 켬 27.9 · 끔 53.9로 다르다. 고침 자체는 새 할당이 없다(모듈 임시 변수 하나). 켬과 끔은 싸움이 다르게 흘러 같은 스텝에서 다른 일을 한다(예: `driveSword`의 부딪힘 계산). 그래서 이 스위치는 할당 A/B로 가릴 수 없다.
