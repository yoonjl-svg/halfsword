# 사장님 질문 세 가지 — 기획 PM 답 (2026-09-30 17:20 KST)

근거: `docs/design/structure_map.md`(main `851d0af`, 정정 1차 반영), 세 방향 문서. 난이도는 하·중·상·최상, 기간은 디렉터+워크플로 체제 어림. 상한·값은 제안하지 않는다.

## 1] 각자 폰으로 대전 — 방식과 난이도
우리 물리는 1/120 s 고정 스텝 + 시드 난수라 "같은 입력 → 같은 결과"가 이미 관문이다. 그래서 첫 후보는 입력만 주고받는 방식.

| 방식 | 어떻게 | 장점 | 문제 | 난이도 / 기간 |
|---|---|---|---|---|
| A. 입력 동기(지연형 록스텝) | 두 폰이 같은 시뮬을 돌리고 손가락·이동·탭 입력만 교환. 상대 입력이 올 때까지 100~150 ms 입력 지연 | 서버 없음(신호 서버만), 대역폭 극소, 구조와 가장 맞음 | 입력 지연이 검술 타이밍을 무디게 함. 두 폰 계산이 1비트라도 다르면 판이 갈라짐 | 상 / 결정성 검증 2주 + 4~6주 |
| B. 입력 동기 + 되감기(롤백) | A에서 지연을 없애고 늦게 온 입력만큼 물리를 되감아 재계산 | 격투 게임 표준, 체감 지연 없음 | 래그돌 세계 전체를 매 프레임 저장·복원 → 폰 CPU 부담. 되감기 6~18스텝 | 최상 / A 뒤 +6~10주 |
| C. 서버 권위 | 서버(Node)가 물리를 돌리고 폰은 입력을 보내고 자세를 받아 그림 | 결정성 불필요, 치트 없음, 헤드리스 시뮬이 이미 Node에서 돔 | 내 칼이 왕복 지연(100~200 ms)만큼 늦게 반응. 서버 비용·운영 | 상 / 8~12주 + 운영 |

권함: A부터, 그 전에 결정성 검증 2주. 위험은 WASM 물리보다 JS 쪽 수학 함수(exp·sin·atan2 — skill.js 필터, gait.js)가 아이폰 사파리와 안드로이드 크롬에서 마지막 자리가 다를 수 있다는 점. 같은 입력 기록을 두 폰에서 돌려 상태 해시를 견준다. 다르면 그 함수를 우리 것으로 바꾸거나(1~2주) C로. 네트워크 허용 결정이 먼저. 사람 대 사람 밸런스는 시뮬로 못 재므로(사장님 규칙) 실제 대전 기록이 필요.

## 2] 인벤토리로 수집·장착해 강해지기 — 난이도 중, 4~6주
| 있는 것 | 새로 필요한 것 | 기간 |
|---|---|---|
| 무기 15·등급·내구·파손, 투구 2(케틀햇·뿔), 판금 2벌(하인리히 13부위·마르그레테 5부위), 갑옷 닳음 판정 | 플레이어 상태(소지품·장착·내구)+저장. 판 준비가 시트 대신 저장 상태를 읽게 | 1주 |
| 카드 뽑기 코드 | 얻는 규칙: 이긴 상대 무기 / 주움 / 뽑기 유지 | 0.5주 |
| 상대 몸 판금 부착 규칙(outfits) | 플레이어 몸에 투구·판금 변형(외형 PM) | 1~2주 |
| — | 인벤토리·장착 화면(카드 v2 문법) | 1주 |
| 근력·검술 보정 값 | 장신구로 올린다면 그 상한(사장님) | — |
위험은 개발이 아니라 숫자: 장비가 상처 문턱을 건드리면 "한 수로 끝나는 결투"가 무너지고 근력이 커지면 늘 일격. 장비 효과를 무기·갑옷(이미 물리)과 근력·숙련(사람 범위 안)으로만 두면 핵심 유지.

## 3] 오픈월드 / 인스턴스 던전 — 난이도 상~최상
없는 것 셋: ① 지형 물리(바닥은 평평한 상자, gait는 평지 전제 — 경사·계단이면 걸음·균형 재작업, 온몸 타격 R2·R4와 같은 자리라 그 뒤여야 함) ② 탐험 카메라·조작(카메라는 상대 고정 어깨 너머, 손가락 하나는 칼) ③ 다대일·지속 세계(AI는 상대 하나, 원형 벽, 판마다 세계 재생성).

| 단계 | 내용 | 기간 |
|---|---|---|
| 허브 + 경기장 | 걷는 작은 야영지(전투 없음) → 문을 열면 결투 무대 | 4~6주 |
| 평평한 인스턴스 던전 | 방-복도-방, 경사 없음, 벽·문·기둥 충돌, 3~5 만남(한 번에 적 하나) | 8~12주 |
| 경사·계단·낙하·다수 적 | 걸음 재설계, 다대일 AI, 카메라 | +10주 이상 |
| 젤다식 오픈월드(물리 상호작용) | 별개 게임 규모 | 6개월 이상 |
로블록스처럼 여러 사람이 같은 세계에 있는 것은 1]의 서버 권위까지 합쳐야 해서 가장 큼. 권하는 순서: 허브+경기장으로 "걷는 세계"를 먼저, 던전은 R2·R4 뒤.

한 줄 비교: 인벤토리(중, 4~6주) < 각자 폰 대전(상, 검증 2주 + 4~6주, 롤백 +6~10주) < 던전(상~최상, 8~12주부터).
