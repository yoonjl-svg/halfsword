# 스태미너 설계안 (2026-10-15)

- 지시: 사장님 10/15 13:5x "스태미너 시스템 설계안 먼저 짜봐. 실제 개발은 샛별에게 맡길게." — 이 문서는 **설계**다. 구현은 샛별 저장소가 맡고, 우리는 들여올 때 관문을 거쳐 붙인다.
- 바탕: 우리 본판 `main` 2481c17 (10/15 13:37 KST). 샛별 저장소는 fdd6455 에서 갈라졌으므로, 그 뒤 우리 본판에 들어온 것(걷기 빠르기 1.8·60 %·40 %, 일본 버티기 `swayScale`, 이탈리아 박자 걸음, 독일 따라 들어가기, 손잡이 끈 메쉬)과 작업 중인 것(첫 걸음 박차기, 디딤 기준 박자 4 + 2, 카메라·무대 훑기)은 **우리 본판을 먼저 합친 뒤** 구현하기를 권한다. 합치지 못하면 해당 자리는 훅(아래 §11 의 `STAMINA.cost.*` 열쇠)만 두고 들여올 때 잇는다.
- 모든 숫자는 **사장님 확인 전 시작값**이다(§10). 들여올 때 확인표(`docs/strike/owner_defaults_table.md`)에 줄을 받는다.

## 0. 한눈에

1. **스태미너 S (0 ~ 상한)** — 동작이 쓰고, 쉬면 찬다. 상한은 피·통증(이미 있는 `vigor`)으로 조금 준다.
2. **쓰는 곳** — 베기·찌르기·막아 받기(받은 충격만큼)·밀치기·일어서기, 그리고 **보법의 빠른 걸음 전부**(박차기·이탈리아 빠른 디딤·독일 따라 들어가기·일본 버티기). 쿨다운 대신 스태미너가 '값'이다.
3. **지치면** — 딱 막지 않는다. 칼 힘·발 가속·균형 회복이 서서히 약해지고, 일본 버티기도 약해진다. 바닥이면 빠른 걸음이 안 나온다.
4. **회복** — 쉬면 빠르고, 걸으면 느리고, **상대 칼끝 앞에서 겨누고 버티는 동안은 더 느리다.** → 한 번 치고 빠져서 숨을 고르는 '들고 나기'가 저절로 생긴다(보법 근본 문제의 2 단계 '거리 싸움'과 맞물림).
5. **보이기** — 숨소리·칼끝이 처지는 자세·화면 가장자리가 먼저. 막대(게이지)는 선택(사장님 결정).

## 1. 왜

- 10/15 보법 점검에서 드러난 것: 빠른 걸음·박차기 같은 이점에 **대가가 없어** 쿨다운이나 문턱을 붙이고 싶어지는데, 사장님 규칙은 '새 쿨다운·문턱은 묻고'다. 스태미너 하나로 남발을 막으면 동작마다 따로 제한을 둘 필요가 없다.
- 사장님 10/15 "일본 보법이 더 많은 스태미너를 소모하는 것으로" — 5 % 감속 대신 스태미너가 대가가 된다.
- 지금 판은 서로 칼끝 바로 앞에 붙어 대치한다. 회복을 거리와 엮으면 **물러나 숨 고르기 → 다시 들어가기**가 의미를 갖는다.

## 2. 원칙

1. **사람 먼저** — 사람이 느끼고 다룰 수 있어야 한다. AI 만 아는 숫자 놀음이 되면 안 된다(유령 동작 금지와 같은 뜻).
2. **물리로 약하게, 딱 막지 않기** — '스태미너 0 이면 공격 불가' 같은 잠금은 두지 않는다. 힘·가속·회복의 배율로 서서히.
3. **AI 도 같은 규칙** — 같은 값을 쓰고, 같은 이유로 지친다.
4. **보이게** — 지친 몸은 눈과 귀로 알 수 있어야 한다(상대 AI 가 지친 것도).
5. **끄면 지금 그대로** — `?stamina=0` 이면 바이트 같음(관문 증명).
6. **이미 있는 몸 상태와 겹치지 않게** — §3.

## 3. 이미 있는 몸 상태와의 관계

| 이미 있는 값 | 지금 하는 일 | 스태미너와의 관계 |
|---|---|---|
| `blood` · `pain` → `vigor` (fighter.js `get vigor`, 0.35~1) | 피가 모자라거나 아프면 힘이 빠짐 — `muscle` 목표에 곱함 | **상한**에만 조금: S상한 = 100 × (0.6 + 0.4 × vigor) → 74~100. 회복·효과에는 곱하지 않음(이중 벌 막기) |
| `muscle` (상태별 근육 힘 0~1) | 넘어짐·일어남·죽음의 몸 힘, 모든 관절에 곱함 | **건드리지 않음** — 지침은 몸 전체 힘이 아니라 칼 힘·발 가속처럼 고른 곳에만 |
| `balance` 휘청임 게이지 (100, 회복 22/s) | 세게 맞으면 줄고 바닥이면 넘어짐 | 지치면 **회복이 느려짐**(§6) |
| `swayScale` (일본 버티기 × 0.75) | 흔들림을 덜 받음 | 버틴 만큼 S 를 씀(§7) · 지치면 버티기 약해짐 — **이미 이 한 자리에 곱하게 만들어 둠** |
| 감정층(공포·분노·집념, ai.js) | AI 간격·공격성 | 건드리지 않음(나중에 '분노면 더 씀' 같은 것은 별도) |
| 월왕구천검 와신상담(다칠수록 힘 ↑) | 공격력 × (1 + 0.3·d) | 상한이 줄어 빨리 지치는 것과 맞물림 — 들여올 때 견줌 |

## 4. 스태미너 값과 회복

- **S** : 0 ~ S상한. 판 시작 = 상한.
- **회복** (초당, 쓴 직후 `delay` 초 뒤부터):

| 상태 | 회복 | 까닭 |
|---|---|---|
| 서 있음 · 상대가 멀리(상대 칼 닿는 거리 + 0.8 m 밖) | 빠름 | 칼을 낮추고 숨을 고른다 |
| 서 있음 · 상대 칼끝 앞(그 안) | 느림 | 겨누고 버티는 긴장(칼을 든 팔·자세 유지) |
| 걷는 중 | 보통보다 느림 | 몸을 옮기는 품 |
| 휘두르는 중 · 막아 받는 중 · 맞는 중 | 0 | 힘을 쓰는 중 |
| 넘어짐·무릎 | 느림 | 일어설 힘을 모음 |

- 거리 판단은 AI 가 이미 쓰는 상대 칼 닿는 거리(`foeReach`, weapon_measured.js) 와 같은 기준을 쓴다(사람·AI 같은 눈).

## 5. 쓰는 곳

| 동작 | 값의 꼴 | 메모 |
|---|---|---|
| 베기 | 한 번에 `cut` × 무기 무게 배율 | 무거운 칼일수록 더(몬탄테 > 롱소드 > 한손 칼). 대안: 칼을 미는 서보 일(토크 × 각속도)을 적분해 그대로 쓰기 — 더 물리답지만 구현이 큼 |
| 찌르기 | 한 번에 `thrust` | 베기보다 적게 |
| 막아 받기 | 받은 충격량 × `parryPerJ` | 칼끼리 부딪힘(combat.js `bladeClash` 의 충격량 J — fighter.js `jolt` 와 같은 값). 세게 받을수록 많이 → '받다 지쳐 뚫림'이 저절로 |
| 밀치기 | 한 번에 `shove` | fighter.js `shove` |
| 일어서기 | 한 번에 `getup` | 넘어짐의 대가를 조금 더 |
| 맞음(몸통) | 맞은 에너지 × `windedPerJ` | '숨이 턱 막힘' — 선택(정할 것 §13) |
| **첫 걸음 박차기** | 한 번에 `burst` | 모자라면 박차기가 안 나옴(보통 걸음) |
| **이탈리아 빠른 디딤** | 빠른 디딤마다 `itFast` | 4 + 2 박자의 빠른 둘 |
| **독일 따라 들어가기** | 빠른 걸음마다 `deChase` | 헛침 뒤 앞 두 디딤 |
| **일본 버티기** | 덜 받은 흔들림만큼 `jpSteadyPer` | 맞음 게이지에서 덜 깎인 몫 + 발 밖으로 덜 벗어난 몫(시간 적분) — 버틴 순간에만 씀 |
| 동방 진보(채택되면) | 걸음마다 `cnAdvance` | 사장님 결정 대기 |
| 비기 | 따로 더하지 않음 | 비기를 이루는 베기·찌르기·걸음이 각자 씀 |

## 6. 지치면

- **피로 k** = S 가 상한의 `tiredFrom`(40 %) 아래로 내려가면 0 → 바닥(0)에서 1 로 곧게.

| 무엇 | 바닥(k = 1)에서 | 자리 |
|---|---|---|
| 칼을 미는 힘(베기·막기 모두) | × 0.75 | fighter.js 칼 서보 힘 `str`(… × mus × …) |
| 발 가속 한도 | × 0.8 | fighter.js driveBalance `lim` |
| 휘청임 게이지 회복 | × 0.5 | fighter.js `balanceRegen` 쓰는 줄 |
| 일본 버티기 | 0 (흔들림 그대로) | fighter.js `swayScale` — steady × (1 − k) |
| 빠른 걸음 (박차기·빠른 디딤·따라 들어가기) | 값만큼 S 가 없으면 안 나옴 | gait.js `fastBegin` |
| 자세 | 칼끝이 조금 처짐 · 자세로 돌아가는 데 조금 더 걸림 | 겨눔 자세(가드) 높이 |

- **탈진(S = 0)** 에도 잠그지 않는다. 아주 약할 뿐이고, 동작을 멈추면 빨리 찬다(§4 '쓴 직후 지연'만 지나면).

## 8. AI

- **같은 값, 같은 규칙.** AI 가 몰아도 비용·회복·지침은 사람과 같다.
- **판단** (ai.js): S 가 상한의 35 % 아래면 '빠져서 숨 고르기'(물러남 Abzug → 칼 닿는 거리 + 0.8 m 밖에서 회복) 쪽 가중을 올린다. 기질의 참을성·공격성이 이 문턱을 흔든다(공격적인 AI 는 더 버티고 더 지친다).
- **상대 피로 읽기**: 보이는 단서(처진 칼끝·숨소리)로만 — `ai_sense.js` 에 `fatigue` 를 '보이는 값'으로 더하되 지연·흐림을 둔다(정확한 숫자를 훔쳐보지 않게). 상대가 지쳐 보이면 몰아붙이는 가중을 올린다.
- 이것이 2 단계 '거리 싸움'(AI 가 들고 나는 박자)의 바탕이 된다.

## 9. 보이기

1. **숨소리** — 피로 k 에 따라 커지는 숨(이미 있는 목소리 표의 `breath` 값·숨 녹음을 다시 씀 — sound.js). 상대 숨도 들린다.
2. **자세** — 칼끝이 처지고, 휘두른 뒤 자세로 돌아오는 것이 느려진다(눈으로 읽히는 '지침').
3. **화면** — 아주 지치면 화면 가장자리(지금 `#vignette`)가 숨 박자에 맞춰 옅게 어두워진다.
4. **막대(선택)** — 지금 HUD 는 체력 막대가 없는 꼴이다. 넣는다면 이동 조이스틱 둘레에 가는 고리 하나, S 가 70 % 아래일 때만 보이게. **사장님 결정.**

## 10. 시작값 (모두 사장님 확인 전) · 맞출 목표

| 열쇠 | 시작값 | 메모 |
|---|---|---|
| `max` | 100 × (0.6 + 0.4 × vigor) | 74~100 |
| `regen.rest` · `regen.guard` · `regen.walk` · `regen.down` | 25 · 10 · 12 · 8 /s | 쉼(멀리) · 칼끝 앞 · 걷는 중 · 넘어짐 |
| `delay` | 0.5 s | 쓴 뒤 회복 시작까지 |
| `restGap` | 상대 칼 닿는 거리 + 0.8 m | '멀리'의 기준 |
| `cut` | 12 × 무기 무게 배율(롱소드 1 · 몬탄테 1.4 · 한손 칼 0.8) | |
| `thrust` | 7 | |
| `parryPerJ` | 0.05 / J | 200 J 받으면 10 |
| `shove` · `getup` | 8 · 15 | |
| `windedPerJ` | 0.03 / J (선택) | |
| `burst` · `itFast` · `deChase` | 12 · 3 · 4 | |
| `jpSteadyPer` | 덜 깎인 게이지 1 당 0.4 | 200 J 맞음 → 덜 깎인 25 → 10 |
| `tiredFrom` | 0.4 | 피로 시작 |
| 지침 배율(바닥) | 칼 힘 0.75 · 발 가속 0.8 · 균형 회복 0.5 | §6 |
| AI 숨 고르기 문턱 | 0.35 | §8 |

**맞출 목표**(구현한 쪽이 시뮬·브라우저로 잼):
- 쉬지 않고 베면 롱소드 6~8 번 · 몬탄테 5~6 번 · 레이피어 찌르기 9~11 번에 바닥 근처.
- 바닥에서 80 % 까지: 멀리 서서 ≈ 3.5 s · 칼끝 앞에서 ≈ 8 s.
- AI 끼리 판 길이는 늘어도 좋다(숨 고르기가 생기므로) — 유파별 승률이 크게 흔들리면 값을 다시.
- 사람: 박차기·빠른 걸음을 마구 쓰면 2~3 번 만에 칼이 무거워지는 것이 느껴질 것.

## 12. 단계 · 시험 · 관문

1. **A 핵심** — S·상한·회복(거리 포함)·베기/찌르기/막아 받기/박차기 비용·지침 배율(칼·발·균형)·숨소리·처진 칼끝 · AI 같은 규칙 + 숨 고르기 판단 · `?stamina=0`.
2. **B 유파** — 이탈리아 빠른 디딤 · 독일 따라 들어가기 · 일본 버티기(비용 + 약해짐) · 이베리아 흐름 할인 · 동방(진보 결정 뒤).
3. **C 다듬기** — 상대 피로 읽기(AI) · 화면 가장자리 · 막대(사장님 결정 시) · 값 맞추기.

- **관문**: `?stamina=0` 이면 지금 본판 관문 값과 바이트 같음을 먼저 증명하고, 켠 값은 새 기대값으로. 48 판 대결은 늘 `main` 인자.
- **시험**: (1) 정해진 입력 플레이어로 '쉬지 않고 베기 → 바닥까지 몇 번' · '바닥 → 80 % 회복 시간(멀리/칼끝 앞)' (2) AI 끼리 판 길이·승률 켬/끔 (3) 브라우저에서 숨소리·자세 확인(사진).

## 13. 정할 것 (사장님)

1. 막대(게이지)를 넣을지 — 감독 권고: 처음엔 **숨소리·자세·화면만**, 막대는 해 보고 읽기 어려우면.
2. '상대 칼끝 앞에선 회복이 느림'(거리와 엮기) — 감독 권고: **넣기**(들고 나기의 바탕).
3. 맞음(몸통)에 숨 빠짐 — 감독 권고: A 에선 빼고 B 에서 시험.
4. 상한을 피·통증으로 줄이기 — 감독 권고: 넣기(74~100 으로 약하게).
5. 이베리아 흐름 할인 · 동방 연환 할인 — 감독 권고: B 에서 시험.
6. 구현 순서 — 감독 권고: 샛별 저장소가 우리 본판을 합친 뒤 A → B → C.
