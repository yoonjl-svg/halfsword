## 3. 대기실 ① 프로필 칸

### 3-1. 무엇을 없앴나
- 3D 미리보기(`lobby_character.js` — 따로 된 WebGL 그리개 · 돌림판 · `lobby_rig.js` 몸 · 장착/투구 미리보기)를 대기실에서 뺐다: `lobby.js` 의 `createLobbyCharacter` · `preview.setWeapon/setArmor/refresh/dispose` · 스킬북 `onBooks` 콜백 · `#characterView` 마크업 · `.character-view` CSS.
- `lobby_character.js` 는 이제 아무 데서도 안 부른다 — 파일은 둠(되돌리거나 '캐릭터 프로필'에서 다시 쓸 수 있게 · 빌드 묶음에는 안 들어감). `lobby_rig.js` 와 `main.js lobbyRigSpec` 도 그대로(`tools/sim/lobby_rig.test.mjs` · `lobby_rig_probe.mjs` 가 씀).
- 장착 · 해제는 그대로 실제 싸움에 간다(미리보기가 없어도 '장착 중' 표시 · 저장 · 싸움 무기 그대로).

### 3-2. 프로필 그림
- 마크업: `<figure class="portrait-card" id="lobbyPortrait"><img id="lobbyPortraitImg"></figure>` — `data-portrait`(프로필 id) · `data-mode`(`original` | `low`) · 못 불러오면 `data-empty`.
- 그림 = `portraitSrc(game.lobbyPortraitId())` — 플레이어(`player`), 시험 길 `?hero=<인물>` 이면 그 인물 그림(변형은 바탕 인물 · 그림이 없으면 플레이어). alt = '<이름> 프로필'.
- **CSS 틀을 빼고 그림 안의 액자 1 을 틀로 씀** — 까닭: 그림에 어두운 갈색 바깥 띠(약 3.8 %) + 금색 이중선 + 모서리 장식이 그려져 있어, CSS 틀을 걸면 틀이 두 겹(14 px 액자 1 + 그 안의 그림 액자)으로 겹쳐 보였다(눈으로 견줌). 그림을 잘라 CSS 틀만 쓰는 길은 인물마다 그림 틀 자리가 1~2 % 씩 달라(바깥 띠 10~12 칸 · 틀 7~9 칸, 314 칸 기준) 조각이 남거나 얼굴 쪽을 잘라 버려 안 씀. 사슬 틀 짝이던 위아래 쇠 장식도 뺌.
- 바탕 `#30261c`(그림 바깥 띠 색 — 그림이 오기 전에도 같은 색 네모) · 그림자 = 전 카드 그림자 그대로(`0 8px 20px`). 못 불러오면 빈 액자 1(같은 틀 그림 · 같은 바탕).
- 보이기: 원본을 줄인 그림은 매끈하게(`image-rendering: auto`) · 예비 low 는 픽셀 그대로(`pixelated`).
