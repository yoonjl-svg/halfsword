# 생사전 (3인의 맹약) — 1단계 설계 · 구현 기록 (2026-10-29)

- 사장님 지시: 10/29 14:1x(첫 말씀) · 14:2x(감독 질문에 답) · 14:5x(결정 묶음). 감독이 전달했다.
- 1단계 = 대기실 칸 · 생사전 화면 · 시간 · 저장 · 캐릭터 카드 · 경기 준비. **실제 2:2 싸움은 2단계**(따로 계획) — 그때까지 모든 경기는 빠른 셈(§5-3)으로 끝난다.
- 싸움 코드(combat.js · fighter.js · ai.js · main.js 싸움 길)는 건드리지 않았다. 관문 해시 그대로(§9).
- 생사전 안의 값은 모두 `src/config.js` `SAENGSA` 한 곳. 사장님이 정한 값과 확인 전 값을 §7 표로 가른다(확인표 2760 ~ 2794).
- 자매 저장소의 생사전 작업은 읽지도 쓰지도 않았다(사장님 14:5x — 따로 설계).

## 1. 사장님 말씀

### 14:1x (첫 말씀 — 감독 전달 요지, 원문 아님)
- 대기실 탭 '이벤트'를 **'생사전'**으로.
- 누르면 대기실 3단 영역(③)에 부제 **'3인의 맹약'**, 짧은 설명, 생사전 기본 설정. 그 칸 맨 아래 **'생사전 입장'** 단추.
- 단추 → **생사전 화면** — 토너먼트 **대진표**.
- 대진표의 경기를 누르면 전투 진입. 거기서 출전할 수 있는 캐릭터 카드와 상태: 부상 여부 · 남은 체력 · 든 무기 · 유파 숙련도.
- 무기는 캐릭터에게 무작위로 배정. 모든 캐릭터는 주 유파만이 아니라 유파마다 숙련도가 있다.
- 내 무기를 캐릭터에게 장착시키면 그 캐릭터는 늘 그 무기를 들고 출전한다.
- 카드 1 장이나 2 장을 눌러 출전할 사람을 고른다.
- 경기가 끝나면 결과를 저장한다.
- 대진은 대략 2시간마다 — 대회를 끝내려면 기다려야 한다.
- 신청은 매일 밤 22:00 ~ 02:00(기기 현지 시각). 대회는 10:00 에 시작.
- 플레이어는 자기 자리 시각에 꼭 싸우지 않아도 된다 — 내 경기는 그 시각 뒤 아무 때나. 결과를 저장한 뒤 2시간이 지나야 내 다음 경기를 시작할 수 있다.

### 14:2x (감독 질문에 답 — 요지)
- **팀**: 나(플레이어) + 동료 둘.
- **둘이 나서면**: 함께 2:2 (2단계 엔진 몫).
- **조종**: 고른 동료는 AI. 내가 나서면 내 몸은 내가, 동료만 나서면 나는 지켜본다.
- **죽음**: 죽은 캐릭터는 이번 대회에서만 빠지고 대회가 끝나면 돌아온다. 빌려 준 내 무기도 돌아온다.

### 14:5x (결정 묶음)
- 조종 — 감독 해석이 맞다(내가 나서면 내 몸은 나 · 함께 나선 동료는 AI · 동료만 나서면 지켜봄).
- **가린 채 고르기**: "그렇게 해" — 두 팀이 동시에 1 ~ 2 명을 고르고 입장 때 둘 다 보인다.
- **대진표 16 팀**: "16팀으로 해" — 10:00 · 12:00 · 14:00 · 16:00 네 대진, 상대 팀 열다섯.
- **경기 사이 회복**: "피는 조금 차고 경상은 2번 쉬면 회복 중상은 회복 불가" — 체력은 쉴 때마다 조금(수는 확인 전) · 경상은 두 번 쉬면 나음(쉼 = 그 캐릭터 팀의 경기와 경기 사이 — k 번째 경기에서 다친 경상은 k + 2 번째 경기 전에 없음) · 중상은 대회 동안 낫지 않음 · 경상 / 중상은 지금 상처 심각도에 문턱을 두어 가른다(문턱 확인 전) · 죽음은 전처럼.
- **기권**: "그렇게 해" — 다음 신청 창이 열리는 22:00 까지 내 경기를 하지 않으면 기권.
- **보상**: 우승하면 보물 상자 **'왕의 하사품'** — 우승 팀은 셋, 준우승 팀은 하나를 연다. 내용은 나중 — 지금은 상자 하나에 **금화 500**(사장님 결정). 다른 물건을 더할 수 있게 내용 표를 둔다 — 사장님이 말씀한 것: 특별한 동료를 고용하는 **'특별한 증표'**.
- **동료 고용**: "동료를 고용할 때 금화를 내는 걸로" — 값 규칙은 작업자 몫(확인 전, 숙련도에 따른 단순한 규칙이면 됨). 나중의 '특별한 증표로 고용하는 특별 동료' 자리만 둔다(증표는 만들지 않음).
- 숙련도 · 전투 성향 표는 다른 작업자(인물 성향 — `src/character_temperament.js`). 여기서는 자리 표 하나를 함수 하나 뒤에 둔다(§4-5).
- **다시보기**: "이번 대회에 한해 다시보기 할 수 있나?" → 2단계(상대끼리 경기가 실제 엔진으로 돌 때) — 씨앗과 저장한 판으로 다시 셈. 지금은 경기마다 씨앗 · 두 팀 출전 · 경기 전 상태 · 판(버전)을 저장만(보는 화면 없음).

### 흐름
1. 대기실 '생사전' 탭 → ③ 칸: 제목 '생사전' + 부제 '3인의 맹약' · 오른쪽 일정 알약 · 설명 두 문장 · 내 팀 세 칸(나 · 동료 · 동료) · 안내 한 줄 · 고용 금화 · '생사전 입장'.
2. 팀 칸을 누르면 칸 안을 덮는 고르기 카드: 동료(로스터 열하나 — 얼굴 · 이름 · 고용 금화) · 이 사람에게 빌려 줄 내 무기(무작위 · 나뭇가지 · 드루이드의 채찍) · 확인. 나(첫 칸)는 무기만.
3. 신청 창 안에서 '생사전 입장' = 이 팀으로 **신청**(고용 금화를 냄 · 무기를 뽑음 · 대진표를 만듦) + 생사전 화면. 창 밖이거나 이미 신청했으면 화면만.
4. 생사전 화면: 대진마다 한 줄(16강 · 8강 · 4강 · 결승 · 우승) · 경기 칸 = 시각 · 남은 시간이나 한 줄 결과 · 두 팀(얼굴 셋 + 'N번 팀' / '내 팀'). 내 길은 왼쪽 금색 줄, 지금 할 수 있는 내 경기는 금색 칸 '입장 가능'. 틀 안에서 내려 보며, 열면 내 경기 자리로.
5. 경기 칸 → 경기 화면(화면 전체 층): 상대 팀 카드 셋 · 내 팀 카드 셋. 내 경기면 내 카드 한두 장 → '전투 입장' → 결과(승리 / 패배 · 결과 줄 · 카드에 경기 뒤 체력 · 부상 · 죽음 · 출전 표시) → '확인'. 다른 경기는 보기만(끝난 경기는 결과까지).
6. 대회가 끝나면 생사전 화면 머리줄에 우승 팀 · 하사품이 있으면 '왕의 하사품 N개를 열 수 있습니다.' + '열기' → 금화.

## 3. 시간 (기기 현지 시각 — `saengsa_clock.js`)

- 대회 날 D: 신청 창 = D − 1 일 22:00 ~ D 일 02:00 · 대진 r = D 일 10:00 + 2 × r 시간(16 팀 = 10 · 12 · 14 · 16시).
- 경기 시작 시각 = max(대진 시각, 두 팀 저마다 마지막 결과 저장 + 2시간). 내 팀의 2시간은 사장님 결정, **상대 팀도 같은 규칙**인 것은 작업자 안(확인 전) — 그래서 내가 늦게 이긴 상대 팀도 2시간 쉰 뒤 다음 경기.
- 상대끼리 경기는 시작 시각이 지나면 저절로 끝난다(결과 시각 = 그 시작 시각 — 화면을 늦게 열어도 같은 기록). 화면은 30 초마다 다시 셈.
- 내 경기 마감 = 다음 신청 창이 열리는 대회 날 22:00. 그때까지 안 하면 기권(결과 시각 = 마감과 시작 시각 중 늦은 쪽 · 체력 · 부상 그대로). 그래서 새 신청 창이 열릴 때는 늘 지난 대회의 내 팀이 끝나 있다 → 새로 신청할 수 있고, 지난 대회는 남은 경기를 끝까지 셈한 뒤 바뀐다(하사품이 남았으면 그때 연다).
- 시험 주소 `?saengsaNow=2026-10-30T09:59` — 열 때 시계를 그 현지 시각으로 옮기고 그 뒤로는 그대로 흐른다(첫 화면은 그대로 뜸).

## 4. 대진표 · 팀

### 4-1. 16 팀
- 내 팀(팀 0 = 나 + 동료 둘) + 상대 팀 열다섯(셋씩). 대진표 자리는 씨앗으로 섞는다. 화면 이름은 자리 차례 'N번 팀'(내 팀은 '내 팀').
- 로스터 = 주 인물(characters.js CHARACTERS) 가운데 방랑 전용 아르토리아를 뺀 **열하나**. 얼터(광기의 ○○) · 손님 인물은 넣지 않는다(감독 지시).
- **겹침**: 상대 팀 45 자리를 내 동료를 뺀 아홉 명이 채우니 한 인물이 다섯 팀쯤에 나온다. 규칙 = 팀장(첫 자리)은 닿는 데까지 서로 다르게 · 나머지 자리는 가장 덜 쓴 인물부터(같으면 씨앗) · 한 팀 안에서는 안 겹침 · 내 동료는 상대 팀에 안 나옴. → §10 여쭘 1.

### 4-2. 무기
- 신청할 때 모든 사람(나 포함)의 무기를 씨앗으로 뽑는다 — 카드 뽑기와 같은 목록(엑스칼리버 복제품 · 빼 둔 무기 · 인물 전용 뺌)과 같은 등급 확률(weapons.js TIER_DRAW · drawWeaponCards 한 장).
- 내 무기(대기실 아이템 칸의 무기 — 지금 나뭇가지 · 드루이드의 채찍)를 한 사람에게 빌려 줄 수 있다(`lendMax` 1 — 확인 전). 그 사람은 늘 그 무기. 대회가 끝나면 돌아온다 — 1단계는 빌려 준 동안에도 대기실 장착 · 다른 판에서 그대로 쓸 수 있다(§10 여쭘 4).

### 4-3. 고용 금화 (사장님 14:5x)
- 동료 한 명 = `hire.base` 20 + `hire.step` 20 × 그 인물의 가장 높은 숙련도(확인 전) — 지금 자리 표로 브론 · 이졸데 · 오마리 40 · 하인리히 · 토메 · 김씨 60 · 랴오 · 마르그레테 · 마야 · 투야나 80 · 미나미 120. 신청할 때 둘 값을 한 번에 낸다(모자라면 '금화가 모자랍니다.').
- 특별 동료(나중 — 특별한 증표로 고용): `saengsa_roster.js` `SPECIAL_COMPANIONS`(지금 빈 표) · `hireCostOf(id)` 가 `{ token }` 을 돌려주는 자리 · 신청은 아직 받지 않음('token').

### 4-4. 대진 경기
- 첫 대진만 두 팀 번호를 적고, 다음 대진은 앞 두 경기의 이긴 팀(`sidesOf`).
- 한 경기에서 진 팀은 대회에서 떨어진다(한 판 승부 토너먼트).

### 4-5. 숙련도
- 인물: `saengsa_proficiency.js` `proficiencyOf(id)` → `{ german, italian, iberian, japanese, chinese, none }`. **자리 표** — 인물 시트 숙련도(자기 주 유파) 그대로 · 다른 유파 = 시트 − 2 · 무유파 무기(none) = 시트 − 1 · 0 아래 없음 · 무유파 인물은 none 이 시트 · 검술을 배우지 못한 브론은 다섯 유파 0. 인물 성향 작업의 표가 들어오면 이 함수 하나만 바꾼다(감독 14:5x).
- 나: 스킬트리 — 그 유파에서 익힌 칸 가운데 가장 높은 급(보법 1 · 막기 2 · 고유 공격 · 심화 3 · 패시브 4 · 비기 5 — skill_tree_data.js NODE_CAT stage) · 무유파 = 다섯 가운데 가장 높은 값 − 1(확인 전).
- 신청할 때 카드에 적어 둔다(대회 동안 그대로).

## 5. 경기

### 5-1. 출전 고르기 (가린 채 — 사장님 14:5x)
- 내 카드 1 ~ 2 장(살아 있는 사람만 · 셋째를 누르면 먼저 고른 사람이 빠짐) → '전투 입장'. 상대 고름은 그때 함께 정해지고(내 고름을 보지 않음) 결과 화면에서 둘 다 '출전'으로 보인다.
- 상대 팀 규칙(확인 전): 체력 `aiPairHp` 40 이상인 사람이 둘 이상이면 가장 센 둘(§5-3 힘), 아니면 가장 센 하나. 상대끼리 경기도 두 팀 모두 이 규칙.
- 조종(2단계): 내가 나서면 `control 'player'`(내 몸은 나 · 함께 나선 동료는 AI) · 동료만이면 `'watch'`.

### 5-2. 부상 · 회복 · 죽음 (사장님 14:5x)
- 부상 = `{ part 팔 · 다리 · 몸통 · 머리, sev, rests }` — sev 는 싸움의 상처 심각도와 같은 잣대(combat.js severity — 1.0 = 뼈를 지날 만한 베기 · 목 0.5 · 머리 베기 0.8 이 죽음 문턱).
- **중상 = sev ≥ `seriousAt` 0.5**(확인 전 — 목 죽음 문턱과 같은 값) · 그 밑은 경상. 같은 부위에 또 다치면 더 깊은 심각도로 합치고 쉰 수는 0 부터.
- **쉼** = 이긴 팀의 경기와 경기 사이(결과를 적을 때 한 번): 살아 있는 사람 체력 + `restHeal` 10(확인 전) · 경상 쉰 수 + 1 → `lightRests` 2 면 나음 · 중상은 그대로.
- 체력 0 = 죽음 → 이번 대회 동안 카드가 흐림 · 못 나감. 대회가 끝나면(새 대회) 모두 돌아온다 — 사람 상태는 대회 안에만 있다.
- 2단계 실제 싸움 상처 → 부상: `injuriesFromWounds(경기 전 부상, fighter.wounds)` — 심각도 `woundMin` 0.1 밑 긁힘은 뺌 · 몸 부위(head · neck → 머리 / chest · abdomen · pelvis → 몸통 / 팔 넷 → 팔 / 다리 여섯 → 다리).

### 5-3. 빠른 셈 (1단계의 모든 경기 · 2단계에도 엔진이 못 돌리는 경기)
- 한 사람의 힘 = (`profBase` 0.6 + `profStep` 0.12 × 그 무기 유파 숙련도) × 무기 등급 몫 `tierK` × 체력 몫(`hpFloor` 0.5 + 0.5 × 체력 ÷ 100) × 부상 몫(경상 0.95 · 중상 0.85 를 하나마다 곱).
- 한 쪽의 힘 = 나선 사람 힘의 합(둘이면 × `pairK` 0.85). 이길 확률 = A² ÷ (A² + B²)(`sharp` 2).
- 진 쪽 한 사람 = 체력 −50 ~ −120 · 이긴 쪽 = −5 ~ −45 × (0.5 + 0.5 × 팽팽함) · 새 부상 확률 진 쪽 0.6 · 이긴 쪽 0.3 · 심각도 0.1 ~ 0.9. 이긴 쪽은 적어도 한 사람이 산다.
- 씨앗 = 대회 씨앗 + 경기 id — 같은 판이면 늘 같은 결과(다시 열어도 · 다시보기도).

### 5-4. 결과 저장
- 경기 결과 = `{ at, winner, entrants { a, b }, fighters { key: { hp, injuries, alive } }, by 'quick' | 'engine' | 'forfeit', seed, ver, pre { a, b } }`.
- `seed` · `entrants` · `pre`(경기 전 두 팀 사람 전부) · `ver`('saengsa-1' — 빠른 셈 · 엔진 셈이 바뀌면 올림)는 2단계 다시보기 몫(사장님 14:5x).
- 내 경기 결과 시각 = 저장한 때 — 2시간 쉼이 여기서부터.

## 6. 보상 — 왕의 하사품 (사장님 14:5x)
- 대회가 끝나면 우승 팀 셋 · 준우승 팀 하나(`chests`). 생사전 화면의 '열기'로 연다 — 하사품마다 내용 표(`chestTable`)에서 무게로 한 줄(씨앗 고정). 지금 표 = 금화 500 한 줄(사장님 결정).
- 나중 줄 예: `{ kind: 'token', id: '…', weight: … }`(특별한 증표 — 특별 동료 고용). 열기 코드는 금화 줄만 지갑에 더하고, 다른 줄은 대회 기록(`t.chests`)에 남는다.
- 연 것을 대회에 먼저 적고 금화를 더한다(두 번 받지 않음). 열지 않고 새 대회를 신청하면 그때 저절로 연다.

## 8. 2단계 연결 (대진표 → 엔진 → 결과)

```text
생사전 화면 '전투 입장'
  setup = matchSetup(t, match, picks, now)      // saengsa_rules.js — 내 경기 · 시각 · 고름 확인 · 상대 고름(가린 채)
    = { matchId, round, seed, mineSide 'a'|'b', entrants { a: [key], b: [key] },
        sides { a: [사람], b: [사람] },            // 사람 = { key, id, weapon, school, tier, prof, lent, hp, injuries, dead }
        control 'player' | 'watch' }
  res = await engine.play(setup)                  // saengsa_engine.js — 1단계 null(빠른 셈) · 2단계 game.launchSaengsa(setup)
    = { winner 'a'|'b', fighters { key: { hp, injuries, alive } } }   // 나선 사람만 · 그만두고 나오면 null(적지 않음)
  playMine(matchId, picks, now, res)              // saengsa_store.js — 다시 확인 → finishMine → applyResult(저장 시각 = now)
```

- 2단계 엔진이 할 일(`main.js launchSaengsa` — TODO 자리 `saengsa_engine.js`): 2:2 판 세우기(나선 사람 · 무기 · 들어올 때 체력 · 부상 반영 방법은 2단계에서 정함) · `control` 대로 내 몸 / 지켜보기 · 판 끝에 위 꼴로 돌려주기(체력 = 판 끝 상태를 0 ~ 100 으로 · 부상 = `injuriesFromWounds(경기 전 부상, fighter.wounds)` · alive = 살아 있음) · 대기실 덮개로 돌아오기.
- 상대끼리 경기도 2단계에서 엔진으로 돌리면 `advance` 의 빠른 셈 자리를 바꾸고, 다시보기는 저장된 `seed` · `pre` · `entrants` · `ver` 로 같은 판을 다시 돌린다.
- 1단계에서 나 혼자 상대 하나와 싸우는 1:1 을 실제 싸움으로 잇는 길(main.js startFight · checkRoundEnd)은 넣지 않았다: 여정 · 방랑 갈래가 판 시작 · 결과 창 · 정지 창 '재대결'(결과를 다시 굴릴 수 있음) · 대기실 돌아오기에 얽혀 있고, 들어올 때 체력 · 부상을 몸에 넣으려면 싸움 코드(fighter.js)를 고쳐야 해서 깔끔하지 않다 — 2단계에서 2:2 와 같이.
