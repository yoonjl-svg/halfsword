# 日本剣道形解説書 (全日本剣道連盟, 昭和56年制定 / 解説書 昭和60年대) 읽기 표

- 근거: 쪽 그림 p01~p42 전부 열람. 쪽 표기 = 그림 파일 번호 `pNN` (책 인쇄 쪽수는 대체로 NN-1: p02=1쪽 … p19=18쪽. p22 이후 일부는 쪽수 없음).
- 표시: [원문] 글로 있음 / [해석] 그림·문맥에서 내가 추정. '?' = 책 글에 없음.
- 책 구성: 상단 = 현대어 해설(본문+注), 하단 = 大日本帝国剣道形 原本(가타카나, 작은 글씨 註). 아래는 현대어 본문 기준, 필요 시 原本 병기.

## 3. 小太刀の形 三本 (打太刀=太刀, 仕太刀=小太刀. p16 제목)
공통: 打太刀 長剣, 仕太刀 短剣 [원문 p15]; 小太刀 3본 모두 小太刀 쪽이 半身 구えで 入身 [해석+원문 p22 「半身の構え、入身」].
- **1본**: 打 諸手左上段(左足から) / 仕 中段半身(칼끝 약간 높게, 右足から). 仕가 入身하려 하면 打 右足 踏み出し 正面 → 仕 「右足を右斜め前に、左足をその後ろに」 体を右に開き 右手 頭上·刃先 後ろ, **左鎬で受け流し** 打太刀 正面 → 左足から一歩ひき 上段 残心 [원문 p16]. 小太刀 중 1본만 제자리에서 相中段 [원문].
- **2본**: 打 下段 / 仕 中段半身(칼끝 약간 낮게). 仕가 入身하려는 순간 打 右足 후퇴 脇構え → 仕 再入身 → 打 左上段 右足 踏み出し 正面 → 仕 「左足を左斜め前に、右足をその後ろに」 体を左 開き **右鎬で受け流し** 面, 打太刀 二の腕 누름(関節よりやや上), 右拳 右腰·칼끝 咽喉 残心 [원문 p17 p19]. 원본: 打 하의 '守る意味'.
- **3본**: 打 中段(立会 間合から 右足·左足·右足) / 仕 下段半身. 打 諸手右上段 正面 → 仕 **すり上げて 打太刀의 右斜めに すり落とし** → 打 右胴 → 仕 「左足を左斜め前」 体 右斜め 開き **左鎬で すり流し** → 打 鍔元에 すり込み 小太刀 鎬으로 누르고 入身, 打 二の腕 누름. 이후 「二三歩進み」 칼끝 咽喉·右拳 右腰·刃先 右斜め下 残心 → 打 右足·仕 左足 相中段 복귀 [원문 p18 p19].
- 끝: 小太刀 끝나면 蹲踞 納刀 → 立会 間合 立礼 → 座礼 退場 [원문 p19].

## 5. 動作 원칙 문장 (직접 인용)
1. 「打太刀(師の位)、仕太刀(弟子の位)の関係を理解して、呼吸を合わせ、原則として仕太刀が打太刀より先に始動しないようにさせる。」 (p22 留意点 四) [원문]
2. 「呼吸は構える時吸気し、前進する時は丹田に気迫をこめ、呼気の勢いで打突させる。」 (p22 留意点 十五) [원문]
3. 「打太刀は一足一刀の間合から技を出し、仕太刀は打突部位に確実に届くよう、気迫をこめて打ち下ろさせる。」 (p22 留意点 十二) [원문]
4. 「形の実施中は、初めの座礼から終わりの座礼まで、特に構えを解いて後退する時も、気分をゆるめず終始充実した気迫で行わせる。」 (p22 留意点 十六) [원문]
5. 「仕太刀は打突後、十分な気位で、残心を示しているか。打太刀は仕太刀の十分な残心を見届けてから始動しているか。」 (p24 着眼点 十) [원문]
6. 「足さばきはすり足で行い、打突した時、後ろ足を残さず前足に伴ってひきつけているか。」 (p24 着眼点 九) [원문] / 목선: 「目付は相手の体から離さないようにする」 (p13 注) [원문]

## 6. 못 읽은 쪽·불확실
