# 한손 칼끝 각 — 옆 자세·두삭 자세 (10/10)

가지 `…/edge-tip2-2q36ha` (기준 main `b23a04e`, 10/9 앞 작업자의 커밋 안 된 일을 3-way 로 얹어 이어 끝냄). 확인표 523~526.

## 1. 사장님 화면 진단 (10/10 05:4x "칼끝 계속 이상하더라")

성 안뜰, 플레이어 한손 칼(손잡이 둥근 막이 — 세이버류), HUD '옆 자세 — 칼을 옆으로 눕혀 뒤로 뺀 자세 · 가로베기 준비'.
그림에서 플레이어 오른손은 머리 높이 어깨 앞에 있고 아래팔은 거의 곧추섰다. 칼은 주먹에서 **옆으로 거의 수평**(올림 0~10°)으로 뻗어 몸 오른쪽을 본다. 칼끝은 상대도 겨누지 않고, 위·아래도 아니며, HUD 글처럼 '뒤로 뺀' 것도 아니다. 손목이 아래팔에 대해 거의 직각으로 꺾여 칼이 깃대처럼 옆으로 나온 꼴이라, 칼을 거꾸로 쥐었거나 가로로 들고 있는 것처럼 읽힌다.
같은 장면을 다시 만들어 재 보니(아래 §3, `onehand_tip2_before_sabre_side_held_game.png`) 칼끝은 **올림 −4°, 방위 +44°**(0 = 상대, + = 칼 든 쪽)였다. 사장님 그림과 같은 꼴이다.

원인은 둘이다.
1. **손가락이 패드에 있을 때(게임에서 늘 보는 꼴)**: 보정 v2 플레이어는 칼끝 방향을 자세표가 아니라 손 매핑 `guardDir(패드)` 에서 바로 읽는다. 이 매핑에서 가슴 높이 옆 패드(0.52, 0.03)는 올림 (0.03 − 0.1)·1.1 = −4°, 방위 (0.52 − 0.05)·1.7 = 46° 가 된다. 두손 칼에선 두 손이 칼자루를 잡아 이 자리가 '옆으로 눕힌 칼'로 읽히지만, 한손 칼은 손 하나에서 칼이 옆으로 튀어나와 깃대처럼 보인다. 브라우저 게임에서는 손가락을 떼도 이 자리가 그대로였다(앞 작업자 그림도 −3.8° · 44.8°).
2. **쉼 무게가 자세표로 끌 때(손 뗀 시뮬·AI)**: guards.js 세이버 표의 감는 자리 다섯(어깨 지붕·옆 자세·옆 지킴과 왼쪽 짝)은 두손 롱소드 감기(칼끝 뒤 145~170°)를 옮긴 값이라 칼끝이 누운 채(올림 −37~+47°) 몸 뒤쪽을 본다. 사장님 10/9 지적 '칼끝이 지면으로 누운 채 내 쪽을 향해 칼을 거꾸로 든 것 같다'가 이 꼴이다.

나머지 후보는 주된 원인이 아니었다: 자세표 목표는 물리로 잘 따라간다(쉼 무게 1 에서 표 값과 실측 차 1~5°, §3-2 — 칼 무게 중심 처짐은 서보 중력 보상이 버팀), 날 세우기 돌림힘은 칼날 축 둘레라 칼끝 방향을 바꾸지 않는다, 손가락 둠에서 실측(−4.4° · 43.8°)이 손 매핑 명령(−4.4° · 45.8°)과 2° 안이라 손목 밧줄·관절 한도·플레이어 손 목표 0.975 가 칼끝을 끌어내리지 않는다.

## 3. 고침 (`JOINTS.oneTip` 'fix' 기본, 'off' = 전 · `?onetip=off`)

1. **손 매핑 칼끝 접기** (`fighter.js oneTipLift`, 한손 칼만): 손을 옆으로 뺄수록(|방위| 26 → 46°) 올림각을 위(55°) 또는 아래(−45°)로 접는다. 가르는 선은 올림 −14°(패드 y ≈ −0.12), ±5° 는 섞는다. 가운데(상대를 겨누는 자리)와 이미 분명히 위·아래인 자리는 그대로. 가로 베기는 칼끝이 위에서 시작해 가운데(맞는 자리)에서 수평이 된다 — 세이버 두삭의 높은 옆 감기에서 내려 베는 꼴.
2. **세이버 표 감는 자리** (`guards.js ONE_HAND_SABRE_TIP`, 세이버·팔쉬온·청강검 감는 자리): 어깨 지붕 [40, 170] → [60, 165], 옆 자세 [30, 150] → [60, 120], 옆 지킴 [−35, 150] → [−45, 60], 왼쪽 어깨 지붕 [45, −160] → [60, −160], 왼쪽 옆 자세 [25, −150] → [55, −120]. 앞 작업자 첫 안의 옆 자세 [30, ±110] 은 칼끝을 옆으로 누인 채라 사장님 10/10 화면 꼴 그대로여서 버렸다.

## 5. 한계

- 접기는 연속 매핑이라 패드 y ≈ −0.12(옆)에 칼끝이 위↔아래로 넘어가는 띠(±5°)가 남는다. 그 띠 위에 손가락을 오래 두면 칼끝이 옆으로 누운 꼴이 잠깐 보인다.
- 교본 대조는 기억에 기댔다(원문 쪽수 미확인).
- 손 높이(옆 패드에서 손이 머리 높이)는 보정 v2 손 매핑이라 이번에 건드리지 않았다(다른 작업자 영역 skill.js 와 맞물림).
