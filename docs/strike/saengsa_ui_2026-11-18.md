# 생사전 화면 셋 — 동료 고르기 · 체력 칸 · 스택 칸 · 2026-11-18

작업 가지 `wk/saengsa-ui` (바탕 dev `d7d05ba1`). 사장님 11/18 말씀 셋(아래 각 절 머리) — 화면만 바꿈(1:1 시뮬 바이트 같음 · §5).

## 한눈에

1. **동료 고르기 = 카드 하나에서 둘을 한 번에.** 동료 칸(둘 중 아무거나)을 누르면 고르기 카드 하나 — 인물 카드를 누르면 고름 · 다시 누르면 뺌(뒤 사람이 앞으로) · 둘까지 · 고른 차례 표 **1 · 2** = 동료 1 · 동료 2. '나' 칸은 고르지 않는다(보이기만). **무기 배정은 없다** — 신청 때 무기를 받지 않고, 생사전 화면 첫 경기의 '무기 배정'에서 처음 받는다. 카드 오른쪽 **가진 무기**(유파마다 묶어 여러 줄로 감음 · 보기만) · 인물 카드마다 **그 인물의 유파 + 내가 가진 그 유파 무기 수**(예 '일본 2' · 0 이면 상태 색).
2. **체력 = 기력 막대 바로 위 10 칸 점선.** 왼쪽 위 이름 · 체력 목록(`#teamList`)을 걷고, 머리 위 기력 막대 바로 위(틈 2 px)에 같은 너비 56 px · 높이 3 px · 10 칸(칸 사이 1 px). 색 ≥ 80 % 초록 · < 80 % 노랑 · < 50 % 주황 · < 20 % 빨강(아군 · 적 같음). 켜진 칸 = **올림**(몫 × 10). 출혈 · 중상 이상이면 어떤 색이든 점멸. 동시 대전 판(생사전 1:1 · 2:1 · 2:2 · 시험 `?team=`)만 — 방랑 1:1 은 그대로.
3. **스택 = 왼쪽 가운데 작은 칸.** 머리 위 기세 칸(기력 막대 밑) · 사냥 발톱 자국(막대 위)을 걷고, 화면 왼쪽 · 높이 38 % 에 스택이 쌓인 몸마다 한 줄(나 먼저): 짧은 이름 · '기세' 칸 10 · '사냥' 칸 5. 1:1 · 동시 대전 같음.
4. **찾은 오류**(§3-1): 옛 머리 위 스택 표시는 숨겨도 숨지 않았다 — CSS `display: flex` 가 `hidden` 속성을 덮어 ① 쓰지 않는 칸이 화면 왼쪽 위 모서리에 점선으로 늘 떠 있고 ② 스택이 0 이 되거나 몸이 죽거나 화면 밖 · 메뉴 · 판 끝이어도 마지막 자리 · 마지막 수로 허공에 남았다(다음 판까지). 동시 대전에서는 상대 머리 위 붉은 세모가 발톱 자국 위에 겹쳤다.

### 3-1. 찾은 오류
- **숨겨도 숨지 않음**: `.ken-pips` · `.hunt-marks` 의 CSS `display: flex` 가 `hidden` 속성(브라우저 기본 `display: none`)을 덮었다. `stamina_hud.js` · `cn_hunt_hud.js` 는 `el.hidden = true` 로만 숨겨서:
  - 스택 판이 아닌 몸(상대 · 셋째 넷째 자리)의 기세 칸이 처음 자리(0, 0)인 **화면 왼쪽 위 모서리에 점선으로 늘** 떴다 (전 사진 `before_stack_1v1_phone844.png` · `before_team_2v2_phone844.png` 왼쪽 위 끝 — 브라우저에서 `hidden: true · display: flex` 를 확인).
  - 사냥 겹이 사라지거나(8 s) 기세가 0 이 되거나, 몸이 죽거나 · 목이 떨어지거나 · 화면 밖으로 나가거나 · 정지 메뉴 · 판 끝이 와도 칸은 **마지막 자리 · 마지막 수로 허공에 남았다**(숨긴 뒤에는 자리 · 수를 새로 적지 않으므로) — 다음 판까지 남음.
- **자리 겹침**: 발톱 자국(막대 위 5 ~ 11 px)이 내 머리 위 느낌표(막대 위 6 px)와 겹치고, 동시 대전에서는 상대 머리 위 붉은 세모(머리 위 0.5 m)가 멀리 선 몸의 발톱 자국 위에 겹쳤다(전 사진 2:2 — 브론 머리 위).
- 기력 무한(용사의 눈물)인 내 몸은 기력 막대를 그리기 전에 돌아가서 **내 기세 칸이 아예 없었다**.
