## 0. 사장님께 다섯 줄
1. 지금 몸은 보이지 않는 손이 몸무게의 20 %(147 N)와 처짐 5 cm 당 130 N 을 더 받치고, 넘어지려 하면 100 %(737 N)로 올립니다. 걷기 힘(±240 N)도 발이 아니라 허공에서 옵니다. 이 힘들은 운동량 장부에 안 적히고, 그만큼 발에서 낼 수 있는 힘이 줄며, 디딜 때의 제동 충격(사람이 '무게를 싣는' 바로 그것)을 지웁니다.
2. C 는 이 힘을 **세 단계로 0** 으로 보냅니다: 먼저 반작용을 발에 실어 장부를 닫고(S1), 다음 선 자세의 수평 밀기와 넘어짐 반사를 다리와 걸음으로 바꾸고(S2), 마지막에 받침과 닻의 기울기 모터를 잰 뒤 끕니다(S3). 단계마다 스위치가 있고 '끔'은 오늘과 바이트까지 같습니다.
3. 베기는 체중 이동과 묶입니다: 손가락이 감기 시작하면 몸무게가 앞발로 옮겨 가고(디딤 = 힘), 손을 떼면 뒷발로 돌아옵니다(되돌림). 거리가 팔+칼보다 멀면 그 차이만큼만 한 걸음 들어갑니다 — 매 베기 앞걸음(H1-A)·0.3 s 내딛기 밀기는 없어집니다.
4. 폰의 짧은 획은 호를 당겨 늘리지 않습니다. 손은 손가락이 간 자리(패드 테두리)까지만 가고, 모자라는 거리는 **몸**(체중 이동 10~15 cm, 필요하면 걸음)이 메웁니다.
5. 샛별이 '바닥 없는 골반 받침'을 **진단**했다면, 우리는 바닥을 **달아 주고 그다음 치웁니다**. 단계마다 잰 수(발 하중 p10, 보이지 않는 힘 N, 장부 잔차)가 관문입니다.

## 1. 한 줄 원리
**서기·디딤·체중 이동(스탠스 위상)을 1급 상태로 두고, 몸무게와 밀기·돌림의 반작용은 오직 발바닥 접촉으로만 땅에 간다 — 베기는 앞발로 체중을 옮기는 일이고, 되돌림은 뒷발로 돌아오는 일이며, 거리는 그 차이만큼의 한 걸음이다.**

### 2.2 1급 상태 `fighter.stance` (새 측정 상태, 힘 아님)
매 스텝 읽기만 하는 값. 모두 이미 있는 것에서 나온다.
- 발 하중 `N_F, N_B` = Rapier 접촉 충격량/dt × 6/7 (gait.js:1061-1067 `groundForce`, 0.19 의 (n+1)/n 과대 보정 — support_optimum §3 '정직 규칙' 과 같은 식). 몫 `wF = N_F/(N_F+N_B)`.
- 지지 다각형 = 딛은 발바닥 자리(`legs[k].plant`·`pinC/pinT`) + `BALANCE.footMargin` 0.14(기하, 기존 값). 무게중심 `f.com`·캡처 포인트 `cp`(1866-1869) 는 그대로.
- 위상 `phase ∈ {double, front, back, swingF, swingB}` = `legs[k].stance` 와 `wF` 에서(걸러진 값, 새 문턱 없음: 0.5 기준 부호).
- 베기 묶음 표지: 기존 사건만 — '새 휘두름'(skill.js:622 `swinging && quiet > 0.2`), `handHeld` 뗌(main.js:1367), `recovering`(skill 642-696), 발 디딤 `touchdown`(gait.js:710).
- 장부(§6 관문용) 열: 중력 Mg · 접촉 ΣN(×6/7) · 발 핀 힘(gait pinFeet 996-1011: 마찰 대리, ≤ μN 검사) · **보이지 않는 힘** = F1+F2 합(수직·수평 따로) + 닻 토크(F3, `uprightJoint` 모터 토크는 Rapier 가 안 돌려주므로 k·e + d·ω 로 다시 계산). 잔차 = ΣN·6/7 + fy_보이지않음 − Mg − M·a_com,y.

### 2.3 S1 — 장부를 닫는다 (수직 힘을 **내부 힘**으로)
- 식: `fy = share · (Mg + k_s(h − y) − d_s v_y)` — 스프링·감쇠에도 share 를 곱한다(1791). 지금은 "받침 0.2" 가 실제론 0.2 + 처짐 몫이라 0 으로 보내도 0 이 안 된다.
- 반작용: `push()` 의 수직 몫을 **딛은 발 발바닥 점**에 `addForceAtPoint(−fy·w_k, sole_k)` 로 싣는다(w_k = N_k/ΣN, 측정 하중 비율; 지금 1775-1785 의 `footLoad` 기하 추정 대신). 발은 땅에 눌리고 땅이 접촉으로 되민다 → 골반↔발 **가상 다리**(엉덩이·무릎과 나란한 직동 구동기) = 운동량이 보존되는 내부 힘. 아직 근육 상한을 우회하는 '보조'이지만, 세계가 모르는 힘은 아니다. 수평 밀기 F2 는 S1 에서 손대지 않는다(발에 실으면 걷다 넘어지는 것이 알려져 있음: config.js:45 주석 — 그 까닭은 2.4 가 고친다).
- 접촉 N 보정 ×6/7 을 `pinFeet` 의 한계 `pinMu·Nf`(gait.js:980-981) 에도 적용한다 — 지금은 마찰 한계를 7/6 배 후하게 잡는다. 정직 쪽으로 좁아지는 것이라 상한이 아니다(엔진 보고 오차 교정).
- 지우는 운동학 강제: 없음(S1 은 힘의 **경로**만 바꾼다). 바뀌는 자리: fighter.js:1775-1798, gait.js:980-981·1061-1067, config.js BODY/GAIT 두 줄.

### 2.4 S2 — 선 자세의 수평 힘과 반사를 다리·걸음으로
**(a) 체중 이동은 다리 IK 로.** 지금 서 있을 때 무게중심을 두 발 사이로 되돌리는 일(gait.js:478-489 `holdGain 1.5`, `sway 466-475`)은 `want` 속도가 되어 F2 외부 밀기로 실행된다. S2 에선 `walking == false` 일 때 F2 를 0 으로 두고, 대신 **딛은 다리 IK 의 엉덩이 목표**를 옮긴다(gait.js `poseLegs` 776-785: `_h.copy(l.hip)` 에 수평 Δ 를 더함):
`Δ = k_shift · (c* − c_xz)`, c* = 지지 다각형 안의 무게중심 목표(아래 2.5 가 정함), c = 실제 무게중심, k_shift 무차원(§3 125).
딛은 발이 핀(20000 N/m, ≤ μN)과 접촉으로 붙어 있으므로, 엉덩이 목표를 앞으로 옮기면 뒷다리가 펴지고(엉덩이·무릎·발목 모터, j.max 560/500/240 × stanceGain 2, maxErr 로 상한) 땅이 발을 되밀어 골반이 간다 — 사람의 발목·엉덩이 전략이다. 새 힘이 아니라 **이미 있는 관절 모터가 이미 있는 핀 발 위에서** 한다. 반작용은 발 → 땅.
**(b) 반사는 걸음으로.** `GAIT.catchMode` 에 `'step'` 을 더한다: need(sag·tilt·offBalance) 가 켜지면 levC 를 올리는 대신 ① 캡처 포인트 걸음(이미 있음: `stumble` 1900-1911 → gait catch 걸음)과 ② 딛은 다리 gain(stanceGain, 이미 lev 로 묶여 있음 gait.js:766)만 쓴다. 보이지 않는 share 복귀는 **일어서기 넘겨받기(levH, 253-263)에만** 남긴다 — 사장님 10/1 "반사 끔은 일어서기가 안 됨" 의 그 몫. 'on'·'fall' 은 그대로 둔다(사장님 상자). 'step' 은 상자 밖이라 §3 127 로 여쭌다.
**(c) 걷는 중**(walking) 에는 F2 를 남기되 S1 처럼 반작용을 딛은 발에 싣는다(수평 몫도). 걷다 넘어지는 옛 문제는 F2 의 반작용이 **정강이 질량 중심**에 걸려 다리를 차 올렸기 때문이라고 본다(1782: `shin.addForce`) — 발바닥 점에 걸면 접촉이 받는다. 틀리면(§7 R5) 걷기 몫은 S3 로 미룬다.
- 지우는 운동학 강제: 선 자세 F2(1800-1807 의 stand·!walking 분기), F4 의 share 복귀(gait.js:264-283 'step' 분기), `skill.lunge` 의 `f.move.y` 덮어쓰기(skill.js:720-724) 와 lunge 발사(622-627) — 2.5 가 대신한다.

### 2.5 베기 = 체중 이동 + 거리만큼의 걸음 (손가락 → 스탠스 명령)
무게중심 목표 c* 는 두 발바닥 자리를 잇는 선 위의 몫 `wF*` 로 쓴다(지금 `weightFront` 0.55 와 같은 좌표, gait.js:481-485).
| 사건(기존) | wF* | 걸음 |
|---|---|---|
| 쉼 | `weightFront` 0.55 | — |
| 감기 중(손 닿음, 아직 swinging 아님) | `weightFront − aW` (aW 첫 후보 0, §3 129) | — |
| 새 휘두름 (skill.js:622 사건) | `weightFront + aS·S` (S = 감기 싣기, 기존 W2 값) | `d > reach_eff` 면 `requestStep('pass', fwd = clamp(d − reach_eff, 0, GAIT.maxStride))` — 길이는 거리에서, 발사는 기존 사건에서. d ≤ reach_eff 면 걸음 없음 |
| 손 뗌·되돌아옴 | `weightFront` 로 돌아감(recoverP 진행에 따라 lerp — 기존 값) | — |
- `reach_eff` = 기하: 팔 0.53(CLOSE.reach 식, config.js:88-90) + 칼자루 + 칼날 − 상대 가슴 반두께 0.11 (롱소드 ≈ 0.53 + 1.18 − 0.11 = 1.60 m, 칼끝이 가슴에 닿는 거리). 새 값 없음. "날의 중간으로 베려면" 은 사장님 질문(§3 131).
- 디딤 시각은 따로 안 정한다: 걸음은 새 휘두름 사건에 요청되고 발 드는 시간은 gait 가 정한다(걸음 0.28~0.7 s, 기존). 봉투 §3 은 발 뗌 −267~−300 ms·디딤 0~+25 ms(칼끝 최고 기준) — 감기 → 베기 한 획이 약 0.3 s 이면 저절로 그 띠에 든다. 들지 않으면 §6 관문 '디딤 시각' 이 알려 준다(고치는 손잡이는 없다 — 시간값 없음, 확인표 Q1).
- 되돌림(뒷발) 은 손을 뗀 뒤 wF* 가 0.55 로 돌아가는 것 **뿐**이다. 뒷걸음은 넣지 않는다(Meyer 의 물러남은 조종 몫).
- 체중 이동 자체가 닿는 거리를 늘린다: 발 사이 0.55 m, wF 0.55 → 0.8 이면 무게중심 +0.14 m, 어깨도 그만큼 앞. 폰 짧은 획이 테두리에서 모자라는 몫의 첫 번째 메움(§5).

### 2.6 왜 이것이 '무거운 힘' 의 자리인가 (A 와의 접점, 계산)
- **마찰 예산.** 다리가 골반을 돌리는 토크는 결국 두 발의 수평 마찰 힘쌍이다: `τ_yaw ≤ μ·min(N_F, N_B)·d_feet` (+ 발 하나의 자유 모멘트 `μN·0.05`, gait.js:1013 의 식). μ 0.9·d 0.55 m: 두 발 50/50 에 Mg 전부면 ≤ 0.9·368·0.55 ≈ **182 N·m**, 받침 0.2 이면 ≤ 146 N·m, wF 0.8 이면 ≤ 73 N·m. A 의 엉덩이 비틀기 토크가 땅에 설 수 있는 천장이 바로 이 수다 — 받침을 걷어 내는 것이 A 의 전제이고, 골반 돌림(−100 ms, 아직 두 발)이 체중 이동(디딤 0 ms)보다 **먼저**여야 하는 까닭도 이 수다.
- **앞발 디딤의 제동 충격.** 걸음 끝에 앞발이 핀되면 몸의 전진 운동량(75 kg × 0.5 m/s ≈ 38 N·s)이 약 50 ms 안에 제동된다 → 발에서 ≈ 750 N 수평. 그 작용선이 무게중심 옆 0.1~0.2 m(fencing 자세 폭 `guardWidth` 0.22) 를 지나므로 **≈ 75~150 N·m 의 yaw 모멘트**가 공짜로 생긴다 — 던지기·타격의 '앞다리 블록' 이다. 지금은 두 겹으로 지워진다: ① F2 가 `want` 를 계속 쫓아 제동을 되밀고, ② 닻 yaw 모터가 생긴 yaw 를 흡수한다(A 몫). C 만으로는 ①이 풀리고, 각운동량은 A 가 닻을 치울 때 골반으로 간다. **C 없이 A 만 하면** 제동 충격이 없어 골반 돌림이 엉덩이 근육 상한(사람 약 60 N·m 비틀기)에만 기대야 하고, A 없이 C 만 하면 충격은 닻이 먹는다. 둘이 한 벌인 까닭.
- 칼끝 빠르기에 C 가 직접 더하는 몫은 작다(무게중심 속도 0.5~1 m/s). C 가 더하는 것은 **닿는 순간 칼 뒤에 있는 질량**이다 — 되튐·밀어 넣기(bind pressure)·첫 상처 J 에서 보인다(§6 관문 '첫 상처 J·받은 J').

### 2.7 S3 — 받침 0, 닻 기울기 0 (잰 뒤)
- `GAIT.assist` 0.2 → 0.1 → 0.05 → 0 을 **같은 하네스로 쓸어 가며** 발 하중 p10·처짐·넘어짐·일어서기를 잰다. 0 은 사장님 상자(0.1~0.3) 밖 — 수가 나와야 여쭐 수 있다(§3 134).
- 닻 pitch·roll(F3): S2 의 다리 IK 가 골반 기울기를 이미 되돌린다(legIK 는 세계 좌표에서 풀어 골반 틀로 바꾸므로 골반이 기울면 엉덩이 모터 목표가 그만큼 반대로 선다, gait.js 895-931). 그러므로 닻 pitch·roll 강성·감쇠를 2500·330 → 0 으로 내리며 tilt·처짐을 잰다. 0 이 되면 **닻 몸체는 yaw 만 남고**, yaw 는 A 가 치운다 → 닻 삭제 조건이 갖춰진다.

## 5. 손가락 입력 매핑 (감기 A 기준) — 호 당김 없이 짧은 획이 닿는 길
입력 사슬은 그대로다: 손가락 Δ → `handOffset`(main.js:1358-1368) → 가죽끈·필터(skill 573-619) → 손. C 는 거기서 **둘을 읽기만** 더한다.
1. **패드 넘침 → 거리.** skill.js:557 이 `handOffset` 을 0.62 로 자르기 전에 `padOver = max(0, |off| − 0.62)/0.62` 를 읽는다(자르기는 그대로 — 손은 테두리까지만). swinging 이고 상대가 reach_eff 밖이면 걸음 길이에 `padOver·stepPer` 를 더한다. 상대가 닿는 거리 안이면 넘침은 **아무 일도 안 한다**(기하 조건이지 문턱이 아님). 세게 멀리 그은 손가락 = "들어가며 벤다" 가 손가락에 실린다.
2. **감기 싣기 S → 체중 이동.** W2 의 S(길이 sL1 0.55 로 1, 넘는 몫은 계속 큼 — 천장 없음) 가 `wF* = 0.55 + aS·S` 로 간다. 작은 감기는 몸무게가 조금, 큰 감기는 많이 앞발로. 손가락 **빠르기**는 어디에도 안 들어간다(PM 빠진 원인 1: 몸 시계는 다리와 땅이 정한다) — 감기의 **크기**와 **방향**만.
3. **짧은 획이 닿는 길 (옛 보정의 호 당김 대신).** 폰 엄지 획 3 cm = 패드 테두리. 손은 어깨에서 0.565 m(팔 길이, armIK d 범위) 까지만 간다. 모자라는 몫을 **몸이** 메운다: ① 체중 이동 +0.10~0.14 m(wF 0.55 → 0.8, 발 사이 0.55 m), ② 가슴 돌림(이미 corrTrunkTurn ex, 783-860), ③ 거리 걸음(1·§2.5). 손가락이 간 곳 밖으로 손을 끄는 일은 없다 — "손가락 = 손, 놓으면 끝"(hair-trigger 4 점) 유지.
4. **되돌아옴.** 손을 떼면(handHeld 0, 0.25 s 뒤 autoGuard — 기존) wF* 가 0.55 로 돌아간다. 뒷발로 무게가 돌아가는 동안 칼은 pad* 로 걷는다(v2 그대로). 새 시계 없음.
5. **AI.** `handOffset` 을 직선으로 옮기는 AI(ai.js:1340-1364) 는 같은 사슬을 타므로 S·padOver 가 저절로 생긴다. AI 의 `gait.requestStep`(1501-1504) 은 §2.5 의 거리 걸음으로 바꾼다(한 자리).
6. **찌르기(탭).** `thrustPose` 의 requestStep 0.3 m 도 거리식으로(d − reach_thrust, reach_thrust 는 찌르기 기하). 이 문서 밖 — 표시만.

## 9. 경쟁자(샛별) 대비 — 모방하지 않는다
| 샛별 | 그들 | 우리(C) | 왜 더 정직하고 더 재기 쉬운가 |
|---|---|---|---|
| A-012 실제 힘·일·운동량 장부 도구 | 장부를 **보고**한다 | 장부가 **닫히도록 힘의 경로를 바꾸고**(S1 내부 힘), 닫힘 잔차(≤ 0.03 Mg)와 보이지 않는 힘 N 을 **단계 관문**으로 쓴다 | 보고는 숫자가 커도 통과한다. 우리는 숫자가 0 이어야 단계가 올라간다. 접촉 N 은 ×6/7 로 교정해 엔진 보고 오차까지 장부에 적는다 |

## 부록 A. 계산 메모
- M 75.1 kg, Mg 737 N. assist 0.2 → 147 N. 스프링 2600 N/m × 0.05 m = 130 N, 감쇠 260 N·s/m. fy 상한 Mg·2.5 ≈ 1842 N. F2 상한 M·3.2 ≈ 240 N.
- 마찰 예산: μ 0.9, 발 사이 `guardLength` 0.55 m, 두 발 50/50 Mg → 0.9 × 368 × 0.55 = 182 N·m; 받침 0.2 → 146; wF 0.8(뒷발 147 N) → 73. 발 하나 자유 모멘트 μN·0.05 = 33 N·m(gait.js:1013).
- 제동 충격: 75 kg × 0.5 m/s = 38 N·s / 0.05 s ≈ 750 N; 작용선 옆 0.1~0.2 m → 75~150 N·m yaw; 무게중심 높이 0.9 m → 675 N·m pitch(앞다리가 받침, 봉투 펜싱 앞무릎 51°).
- 체중 이동 거리: wF 0.55 → 0.8 × 0.55 m = +0.14 m(어깨도 같이) → 0.3 s 면 평균 0.46 m/s, 운동량 35 N·s.
- reach_eff(롱소드): 0.53 + 0.13 + 1.05 − 0.11 = 1.60 m(칼끝이 가슴에). 날 중간(칼끝 −0.3 m) 기준이면 1.30 m — 사장님 질문(§3 131).
- 봉투 시각(칼끝 최고 0): 발 뗌 −267~−300 · 골반 −108~−92 · 가슴 −58~−33 · 손 −67~−42 · 디딤 0~+25 ms. 순서: 두 발 위에서 골반 돌림(마찰 예산) → 한 발 → 디딤 제동(체중 이동 완성) → 칼끝.
