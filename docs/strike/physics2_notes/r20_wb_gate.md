## 3. 정의와 고른 것 (줄마다 · 까닭)

- **재는 셈은 한 벌**: r13 `vs_src.mjs` 의 표본 · 발 닿음 · 획 셈 · 장면을 `tools/sim/wb_measure.mjs` 로 옮겼다. `vs_src.mjs` 는 이제 그것을 불러 쓴다(씨앗 9001-9003 찌르기 · 베기로 옮기기 앞뒤 json 이 바이트까지 같음을 확인). 관문 셈 `strokeWB` 는 같은 파일 안에 따로 있다(r13 표의 정의는 그대로 둠).
- **앞** = 획을 시작한 스텝에 내 골반 → 상대 골반의 수평 방향. 그 뒤 고정한다(몸이 돌아도 바뀌지 않음). 자료는 과녁 쪽 한 축(힘판 · 카메라 x 축)으로 쟀다.
- **골반** = 골반 강체의 질량 중심 빠르기 중 앞 몫. 자료(Hassan · Klauck)는 엉덩 표지의 수평 빠르기다.
- **무기 든 손** = 칼 쥔 아래팔 끝(harness `handPos` — 손목)의 수평 빠르기 크기. 자료는 가드(손 바로 앞)의 수평 빠르기다.
- **첫 움직임 t0** = 획을 부른 스텝(사람 = 탭 · 손가락 시작 / AI = 휘두르기가 켜진 스텝 · 레이피어 AI = 탭)과 '손 시작' 가운데 이른 쪽. 손 시작 = 손 앞 빠르기 − 골반 앞 빠르기가 0.5 m/s 를 **아래에서 위로 넘는** 첫 스텝(부르기 0.25 s 앞부터 찾음). 찾기 처음에 이미 넘어 있으면(앞 동작이 이어지는 중) 다시 내려간 뒤 넘는 것만 치고, 못 찾으면 t0 = 부른 스텝(관문이 그런 획 수를 찍음 · §6 지적 6). 자료의 움직임 시간도 몸의 첫 움직임에서 잰다(반응 시간 뺌). 걷는 중인 AI 가 걸음 때문에 시작으로 잡히지 않게 손 시작은 골반 빠르기를 뺀 값으로 본다.
- **맞음** = t0 ~ t0 + 1.5 s 안에 이 몸이 상대에게 낸 첫 상처(combat onWound) · **다음 동작 앞**. 다음 동작 = 이 몸의 다음 획이거나, 재지 않는 동작이라도 바쁨(탭 또는 휘두르기)이 꺼짐 → 켜짐으로 바뀐 스텝 — 단 같은 AI 기술 안의 다음 휘두르기(들기 → 치기)는 같은 동작. 자료는 전기 득점 · 과녁 스위치다.
- **재는 창** = t0 ~ 맞음. 못 맞은 찌르기는 t0 ~ 칼끝이 상대 골반에 (수평으로) 가장 다가선 스텝(t0 + 1.5 s · 다음 동작 앞까지 안에서) — 획 뒤 걸음 · 다음 동작을 창에 넣지 않으려고(§6 지적 5). 못 맞은 베기는 C2(지킴)의 창을 바꾸지 않으려고 t0 + 1.5 s(다음 동작 앞까지). 기술 깃발(swinging · tap)이 켜진 동안만 재지 않는다 — 앞 도구가 그 실수로 부푼 수를 냈다.
- **넘어짐** = t0 ~ t0 + 3 s 에 state 가 stand 가 아닌 스텝이 있음(down · getup · dead). **돌아옴** = 창 끝 뒤, t0 + 3 s 안에 선 채 두 발이 땅에 닿고 · 탭/휘두르기가 꺼지고 · 골반 높이가 시작의 90 % 넘는 스텝이 있음. 넘어졌거나 안 돌아온 획은 획으로 세지 않고 따로 센다(관문 줄의 머리 · 굳은 금 2). 3 s 를 못 본 획(싸움이 끝남)은 '끝 잘림'으로 뺀다.
- **L3 뒷다리 밀기** = 이 획의 앞발이 뜬 스텝 ~ 내려앉은 스텝(3 스텝 내리 닿음) 안에서, 앞발이 떠 있고 뒷발만 닿은 스텝의 몸 전체(토막 + 칼) 앞 운동량 변화율(± 4 스텝 가운데 차) 최고 ÷ 몸무게. 그 밖의 한 발 딛기(걷는 걸음)는 세지 않는다(§6 지적 5). Rapier 0.19 는 접촉의 접선 충격량을 주지 않아 발 하나의 땅 반력을 직접 못 읽는다(r13 과 같은 셈 · 앞을 고정한 것만 다름). 앞발이 뜨지 않은 획은 이 줄에 들지 않는다.
- **L5 손 · 앞발** = 앞발이 뜬 스텝(3 스텝 내리 떨어짐 · t0 − 0.2 s 부터) − 손 시작. + 이면 손이 먼저. 앞발 = 시작 때 과녁 쪽으로 더 나간 발.
- **L6 차례** = 맞은 획에서 뒷다리 엉덩 · 무릎 · 발목의 상대 각속도 꼭대기 스텝이 **엉덩 < 무릎 < 발목**(같은 스텝 = 차례 아님)인 몫. 꼭대기가 맞은 스텝에 걸린 획(아직 오르는 중 = 잘린 꼭대기)은 셈 밖. 관문이 '같은 스텝' 수와 '잘려 뺌' 수를 찍는다(§6 지적 2). 자료는 '밀기의 %' 다(80 → 88 → 94 % · 밀기 단계를 따로 정의하지 않음 — r13 과 같음).
- **C1 앞발 디딤 − 칼 닿음** = 내려베기에서 t0 − 0.3 s ~ 맞음 + 0.2 s 에 처음 뜬 발(딛는 발)이 3 스텝 내리 닿은 첫 스텝 − 맞음. Takenaka 는 검도 머리 치기(세로)에서 밟는 발 닿음과 칼 닿음(과녁 테이프 스위치)을 쟀다. 사람 길 내려베기 = 세로 + 사선 + 세로 둘째(장면 난수 씨앗 + 100000 · 사선이 서 있는 과녁을 자주 빗나가 맞은 획이 40 언저리였음), AI 길 = zornhau · zornhauL · oberhau.
- **C2 칼끝 최고 빠르기(지킴)** = 내려 + 가로 베기 모두의 칼끝 빠르기 최고 가운데값이 오늘 범위(r14 표 · 사람 13.3 ~ 15.3 · AI 12.0 ~ 13.4) ± 10 % 안.
- **베기는 장검만**: 자료(Merkert · Takenaka)가 두 손 칼 · 죽도의 값이라 레이피어 베기는 견줄 수 없다. 레이피어는 런지 줄에만 든다.
- **베기 획은 넘어짐만 뺀다**(돌아옴은 안 봄): AI 는 베기 뒤 곧 다음 기술로 이어가는 일이 잦고, '자세로 돌아옴'은 런지에 붙은 조건이다.
- **판정** = 가운데값이 과녁 안(L6 · C1 은 몫). 그 줄이 기댄 획(맞음만 쓰는 L4 · L6 · C1 은 맞은 획)이 **40 넘게(≥ 41 · r14 §3 '40 획 넘게')** 가 아니면 "TOO FEW" — PASS 로 치지 않는다. GATE 는 판정 줄 모두 PASS 일 때만 PASS. 줄마다 씨앗 단위 부트스트랩 90 % 구간을 함께 찍는다(획은 씨앗 안에서 뭉치므로 씨앗을 다시 뽑음). **두 묶음 규칙**: 한 줄은 두 묶음 모두 PASS 일 때만 통과(`blocks.mjs` 의 '두 묶음' 칸 · 한쪽만 = SPLIT).
- **과녁** = r14 §1 표의 값 그대로(자료 범위 ± 20 %). ± 20 % 는 r14 가 넓게 잡은 것이지 자료가 준 수가 아니다.

## 5. 안 한 것 · 남은 것

- 본판 96162667 은 합쳤고(§0) 관문 · 굳은 금을 합친 나무에서 다시 쟀다.
