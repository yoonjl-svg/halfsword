과제: 걷다가 받은 런지가 앞발로 나가게(채비 → 모아 딛기 → 런지 → 디딤 → 되찾기), 칼과 발이 같이 닿게, 런지 걸음 안에서는 몸이 더 실리게.

### 2-2. 채비 — 런지 부탁을 받은 때부터 런지 발이 뜰 때까지 가려는 속도 0

## 5. 넓히면 (모든 동작으로)

여기서 한 것은 '런지' 하나에 대한 세 칸짜리 차례다: ① 채비(앞으로 가던 몸이면 가려는 속도의 앞 몫을 0 으로 — 다음 동작이 쓸 몸 빠르기를 미리 만든다) ② 준비 확인(캡처 점 셈 `lungeFit` — 이 동작을 지금 자세에서 받을 수 있나)이 거짓이면 한 번 모아 딛기
③ 실행(런지 걸음 — 이 동안만 옆 조종을 끊음) ④ 디딤 · 되찾기(예전 그대로). 팔(탭 찌르기)은 ③ 의 남은 시간을 보고 뻗기를 시작한다.
넓힐 때의 꼴: 동작마다 { 준비 확인(받을 수 있는 몸 상태 — 캡처 점 · 빠르기 · 발 자리), 채비 걸음(못 받으면 무엇으로 받게 만드나), 실행 동안 끊을 조종 몫, 팔이 맞출 때(디딤 · 무게 옮김) } 네 칸의 표.
지금은 gait.js 의 `req` 가지와 skill.js updateThrust 에만 있다. 베기(AI 베기 걸음 · stroke)의 팔은 아직 디딤에 맞추지 않는다 — 같은 꼴(팔 시간표를 런지 발 남은 시간에 걸기)로 updateStroke 에 넣으면 된다.
되먹임 오차 배우기(같은 동작을 되풀이하며 채비 몫을 고치기)는 하지 않았다 — 채비 몫이 0 하나라 배울 것이 없었다.
