## 3. 본판(main)에 붙이는 법 — 디렉터 몫

`physics2_proto/trial_page_main.patch` 를 main 에 붙인다(`origin/main d6ea393c` 에 `git apply --check` 통과). 세 곳이다.

1. `.github/workflows/deploy.yml`: `physics-2` 의 **정해 둔 커밋**(`95f435c0`)을 `.p2` 로 따로 받아 `node tools/physics2_page/build.mjs` 를 돌리고, 다 지은 뒤에 `public/physics2` 로 옮긴다. 두 걸음 모두 `continue-on-error` 와 시간 한도(5 분 · 10 분)가 있어 실패하거나 멈춰도 본판 배포는 간다(시험 페이지만 빠지고, 본판 빌드 뒤의 걸음이 경고를 찍는다). 받기가 실패하면 빌드 걸음은 돌지 않는다.
2. `tools/pwa/build.mjs`: `EXCLUDED_DIRS` 에 `physics2` 를 더한다(본 게임 오프라인 목록에서 뺌 — 서비스 워커는 목록 밖 주소를 가로채지 않는다).
3. `.gitignore`: `public/physics2/` · `.p2/`.

- 커밋 해시로 고정했다(검토 권고): 같은 출처라 검토한 판만 나가게 한다. 시험 페이지를 새 판으로 바꾸려면 `deploy.yml` 의 `ref` 를 올린다. `physics-2` 에 푸시만 해서는 안 바뀐다.
- 걷는 법: 위 세 곳을 되돌리면 다음 배포에서 `/physics2/` 가 사라진다. 시험판 저장(`stillness.p2trial.*`)은 폰에 남지만 본판은 읽지 않는다.
