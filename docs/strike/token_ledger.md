## 띄울 때 지킬 것 (감사 11/26 18:17 UTC)

1. 큰 짓기 일꾼(맥락 15만 넘음)은 이어 부르지 않는다 — 지적 고침은 새 일꾼에게 차이 · 닿는 함수 · 지적 · 넘겨받을 메모만 주어 맡긴다. 맥락이 작은 일꾼(설계 따위)만 이어 부른다.
2. 일꾼 하나의 맥락은 40만을 넘기지 않는다 — 35 ~ 40만에 닿으면 넘겨받을 메모(바꾼 것 · 해 보고 안 된 것 · 다음 할 일 · 결과 표의 자리)를 남기고 끝낸다. 짓기 일꾼은 끝날 때 늘 이 메모를 남긴다.
3. 선임의 직접 호출을 줄인다 — 호출이 네 번을 넘길 일(대본 돌려 재기 · 표 만들기 · 까닭 가르기 · 자료 읽기)은 작은 맥락의 심부름 일꾼(둘째 등급 · 재는 것은 여전히 대본)에게 맡기고 선임은 결과 파일만 읽는다.
4. 감사 알림은 과제 합이 100만 이상일 때의 다섯 줄만 — 합계는 이 장부에 적는다.
