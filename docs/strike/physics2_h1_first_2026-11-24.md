**힘 몫은 선 힘(밀고 받치는 힘)만의 몫이다 — 닻 토크는 들어 있지 않다.** 숨은 힘 전체가 25 ~ 35 % 라는 뜻이 아니며, 토크 몫은 각운동량 잔차를 붙일 때 함께 낸다(감사 11/24 대조 2). 서기 장면의 일 몫은 몇 J 끼리의 비라 읽지 않는다 — 서기는 힘 몫만. 힘 몫 = ∫|F_밖|dt ÷ (밖 + 땅 · 접촉 · 발 핀). 일 몫 = ∫|P_밖|dt ÷ (밖 + 안쪽 일률). 닻 토크는 넘어간 k · d 로 다시 센 값(± 20 % 쯤).

## 읽기 (잰 것만)

1. **몸을 받치고 미는 층은 9/30 보다 조금 나아졌고 11/1 뒤로는 그대로다.** 받침 몫 28 % → 19 %(10/1 받침 0.3 → 0.2). 11/1 과 지금은 대본 장면 숫자가 모두 같다. 사장님이 느끼시는 "몇몇 왜곡은 오히려 심해짐"은 이 층에서 온 것이 아니다 — 판정 · 규칙 층(H3)과 직접 쓰기에서 찾아야 한다(다음 재기).
2. **걷기는 다리가 아니라 밖 힘이 한다.** 4 s 걷는 동안 걷기 밀기가 +658 J 를 넣고 −570 J 를 뺀다. 체중 75 kg 이 걷는 빠르기의 운동 에너지는 수십 J 다.
3. **헛친 반동을 발이 아니라 밖 힘이 받는다.** 여섯 획 동안 걷기 밀기가 −98 J · 닻이 +97 / −67 J. 근육 쌍이 넣은 일은 +418 J — 휘두름에 든 더한 일의 약 14 ~ 19 % 가 닻에서 온다(선언 근육만 분모로 97 ÷ (97 + 418) = 19 % · 허리 · 다리의 엔진 모터 근육까지 든 안쪽 더한 일 608.6 J 로 나누면 14 % — 감사 11/24 대조 3).
4. **가만히 서 있어도 밖 힘이 체중의 19 % 를 받치고(설정 0.2 와 맞음), 수평으로 평균 77 N 을 민다**(307 N·s ÷ 4 s).
5. **새로 찾은 것 — 내딛는 발 당김(`gait.js swingPull`)**: 발과 골반에 같은 크기 반대 힘을 걸어 선운동량은 맞지만 작용선이 달라 짝힘 토크가 남는다. 걷기 4 s 에 326 N·m·s(평균 81 N·m) — 닻 기울기 토크(368)와 같은 크기의 숨은 토크다. 지금까지의 목록에 없던 항목.
