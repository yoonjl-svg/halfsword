## 6. 지은 것과 자리 (재는 칸 `$S/r41/cells/pierce1` · 패치 `docs/strike/physics2_proto/r41/pierce1.patch` · src/combat.js 하나 · tools 바뀜 없음)
- `PIERCE` (combat.js 머리 · 내보냄): FP 10 N [Ní Annaidh 원문 · 빠른 찌르기] · XP 0.02 m [Gilchrist 원문] · FF 0 [확인 전] · cosAxis 0.7 [확인 전 · r38 A · B] · reach 0.005 m [확인 전]. 재는 대본이 FP · FF 만 바꿔 돌림.
- `filterContactPair`: 칼날 쌍에서 칼끝 장부가 있으면 0 · 없고 (cutting 이 없거나 아직 안 닿음 applied=false) `pierceGate` 가 열리면 cutting 을 버리고 장부를 엶 → **칼끝 문이 '가를 수 있다' 예측보다 먼저.** 이미 닿아 가르는 중(applied)인 쌍은 옛 길 그대로. 장부 열쇠 = 공격자 · 몸 콜라이더 (그 칼의 모든 칼날 콜라이더). 칼자루는 굳은 닿음 그대로.
- `afterStep` 첫머리: `pierceShapes`(몸 콜라이더 모양을 한 번 떠 둠 — 걸이 안은 엔진을 못 부름) → 장부마다 `pierceStep` → 같은 칼 · 토막의 안 닿은 cutting 버림. 힘 사건(C 길)은 장부 쌍을 건너뜀.
- `pierceStep`: 겹침 = 칼날 ↔ 토막 엔진 닿음 목록의 contactDist < 0 **또는** 지금 칼끝이 토막 모양 안 (목록이 스텝 앞 자리라 한 스텝 늦어서). 처음 겹치면 E = 칼끝 뒤 0.6 m 에서 칼 축으로 쏜 광선이 그 모양(상자 · 공 · 캡슐 — 엔진 모양 값)에 닿는 점 · Lexit = 반대쪽 겉까지 · `strike(pr, 점, false)` 한 번(오늘 판정 · 쉼 · landed 그대로 · 되튐 없음). 깊이 d = (칼끝 − E)·u (u = 들어온 칼 축 · 토막 좌표에 고정). 천막: d 를 XP 까지로 자른 스프링 K = FP/XP + 임계 감쇠 2√(Kμ) · **묵시 적분** · 밀어내기만 · 한 스텝 FP·dt 넘지 않음 · d ≥ XP 면 뚫림. 뚫린 뒤: FF 를 축 상대 움직임 반대로 (≤ μ|s|). μ = 칼 + 손(gripMass) 과 토막(bodyMass) 의 줄인 질량. 힘은 칼끝 점에 칼 −J · 토막 +J. 끝: 겹침 없음(clear) · 칼 놓침(gone) · 안 듦(miss).
- 재는 대본 `docs/strike/physics2_proto/r41/`: pierce_depth.mjs (장면 · 장부 · 검산) · pierce_table.mjs (표 ① ~ ⑤) · gate_vs_nf.mjs (r36 nf 기록과 판마다) · honesty_fp.mjs (심판을 FP 수준으로) · hon_table.mjs · run_all.sh · run_honesty.sh.

## 7. 해 보고 안 된 것 · 못 가린 것
- 처음 판: 들어옴을 엔진 닿음 목록으로만 봄 → 한 스텝 늦어 첫 겹침 때 이미 d > 20 mm, 천막 힘 0 으로 다 뚫림. → 칼끝이 모양 안인지도 보게 고침. 천막 감쇠가 FP 230 에서 FP 를 넘어 → 한 스텝 FP·dt 로 자름(임계 감쇠의 뜻에서 벗어남 — 적어 둠).
- 빠른 칼끝은 한 스텝에 천막(2 cm)을 넘는다(2.4 m/s = 2 cm/스텝) → 천막 일은 FP·s·dt 로 어림됨(½·FP·XP 의 2 배까지) [어림].
- **옆 버팀 없음** → 몸 안 칼이 옆으로 자유롭게 움직임 · **다른 토막 굳은 닿음** (3 의 못 넘은 줄) · 꿰뚫은 뒤 깊이(몸 밖으로 나간 길이)도 깊이로 셈 · 장면 끝까지 몸 안에 남는 칼.
- μ 에 팔이 안 듦(칼 + 손만) — 감쇠 · 상한이 실제보다 작게 잡힘. 엔진 닿음 목록 한 스텝 늦음. 정직 심판 표본이 작음(2 씨앗 · 장검 판엔 칼끝 듦 없음). '멈춘 것' 가름(0.3 m/s · 차례)은 내가 정함.
- 문 정의가 push_depth 와 칸마다 ±1 로 안 맞음(4). 판정과 같은 '찌르기 갈래' 를 쓸지, B 처럼 법선만 볼지 정해야 함 — 장검 수가 3 ~ 17 배 갈림.
