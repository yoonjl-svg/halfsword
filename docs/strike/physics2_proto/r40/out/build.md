## 1. 지은 것과 자리 (패치 3 파일)
| 파일 | 바꾼 것 |
|---|---|
| `src/config.js` ARM | `wristLimit: 25` 한 줄 + 주석 (새 값 아님 = 심판이 써 온 25) |

| `tools/sim/honesty.mjs` | `WRIST_JUDGE = { limit: CFG.ARM.wristLimit }` · 관절 표 `[/^sword/, WRIST_JUDGE.limit]` (옛 못박은 25 대신) · 두 손 칼(`weaponCfg.twoHand`)일 때만 칼 관절 가름 쌓기 + 요약 `swordSplit` · 보고 한 줄 · config 에 값이 없으면 경고 한 줄 |
- 가름 정의(r37 `wrist_split.mjs` 와 같음): 전달 잰 값(meas = 엔진 관절 + 몸 안 쌍 선언) − 지렛대(갈래 `offhand` 가 칼에 건 힘의 칼 관절 점 둘레 모멘트) = 손목 관절 몫(서보 + 관절 구속). 두 손 사이 = 빈손 힘 점 ↔ 칼 관절 점 거리. 지렛대 > 두 손 사이 × 150 · 250 N 몫(금 없음).
- 가름 표는 칼이 안 닿은 스텝(farFree)만 · 닿은 스텝까지 넣은 손목 몫 최고 · 넘은 몫을 덧붙임. 옛 줄(`joints.sword`)은 글자 하나 안 바뀜.
- 다리 잣대(LEG_JUDGE)는 '못박고 config 와 견줌' 꼴인데, 과제대로 손목은 config 를 **읽는** 꼴로 함(몸이 자르는 값 = 심판 값). 이 차이는 선임 판단 거리.
- 새 대본(재기만): `docs/strike/physics2_proto/r40/w1_sum.mjs` (wrist_split 결과 → wr > 25 · > 26 몫 · split_sum 과 같은 스텝 고르기).
