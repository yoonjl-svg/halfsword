# 훈련장 설계에 넣을 것 — 감사(직관)의 지적 · 11/26 18:36 UTC · 물리 2.0 이 따르기로 함

요지: "무게를 실으려면 손이 몸보다 늦게 나간다"(설계 §12-2)는 던지기 운동의 답이지 검술의 답이 아니다.
- 검술서의 차례는 손이 먼저다. 실버의 "참된 때"는 손 → 몸 → 발이고 발이 먼저면 "거짓 때"다. 지간티는 팔을 먼저 뻗고 몸이 따르라 하고, 링엑은 발이 베기를 "따른다"고 적었고, 검도의 기검체일치는 "함께 닿는다"다.
- 투수의 와인드업에 해당하는 것은 검술에서 "자세"다. 높은 자세가 이미 감아 둔 몸이다(#12 coil). 감아 둔 것을 풀고(#12), 몸이 돈 만큼을 손에 싣고(#11 carry), 발이 칼과 함께 닿고(#17~19), 손목을 늦게 푼다(#7·8).

고칠 것 셋:
1) 첫 훈련의 과녁 = "기준보다 늦게 닿지 않으면서(덧금 0 ms) 가장 실린 칼". 손 늦춤(#5 handDelay)은 0 에 묶고 먼저 찾는다. 그것으로 모자랄 때만 #5 를 풀고, 몇 ms 를 내줄지는 그때 사장님께 여쭌다(§12-2 는 그 뒤로 미룬다).
2) 차례의 자유도를 양쪽으로 연다. 지금 표에는 끝쪽이 늦는 수(#3·5·6·7)만 있고 몸이 손보다 늦게 떠나는 수가 없다. 골반에도 늦춤 하나(0~0.1 s)를 준다. 무엇이 맞는지는 훈련과 자료가 정한다.
3) §8-1 의 "차례 70 % · 다리 몸통 몫 20 %"는 성공의 조건에서 빼고 읽어 두는 값으로만 쓴다. 성공은 "늦지 않음 · 진짜 에너지 오름 · 발과 칼이 함께 닿음(±50 ms) · 손목이 늦게 풀림 · 굳은 금 통과". 그 두 수는 자료 조사(r12_sources.md §8 "무엇이 먼저 떠나는가")가 숙련 검객의 실제 값을 가져온 뒤에 다시 정한다.
