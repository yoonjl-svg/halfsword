# 본판에 올릴 두 고침 — 근거 묶음 (2026-11-26)

**결론 먼저.** 두 고침(팔 근육 셋째 판 · 다리 한도 250)을 본판 `origin/main`(bd9ca2b2)에 둘 다 얹은 판에서 단위 시험 982 개 가운데 **942 개가 통과**한다(본판 947). 본판에서 통과하다 합친 판에서 깨지는 시험은 **일곱**이다. 그 가운데 **진짜로 몸이 달라져 깨지는 것은 하나**(두 팔 엇갈림 D — 왼쪽 자세에서 두 팔이 3.6 cm 겹침 · 문턱 몫 0.05 에 0.051)이다. 나머지 여섯은 씨앗 운이거나, 판정을 다시 지어야 하는 것이거나, 칼집 규칙의 빈틈이다. 본판에서 깨지다 합친 판에서 통과하는 시험은 둘이다(일본 서 있는 자세 · 리솔루토 닿는 끝).

싸움 · 막기 · 마무리 찌르기는 **고침마다 따로** 쟀다. 두 고침을 합친 판에서는 재지 않았다(4 절).

## 4) 합친 판에서 재지 않은 것

- 싸움(96 판) · 막기 · 마무리 찌르기 · 다리 묶음 · 팔 명령 튐은 **고침마다 따로** 쟀다(팔 = bu_4_120 · 한도 = bh_250). 두 고침을 합친 판에서는 재지 않았다.
- 합친 판에서 잰 것은 단위 시험 982 개와, 위 3-1 · 3-2 의 시험 장면을 씨앗 8 ~ 16 개로 다시 돌린 것뿐이다.
- 두 고침은 다른 곳을 건드린다(팔 근육 셈 · 다리 토크 한도). 그러나 넘어짐은 둘 다 줄였기에, 합친 판의 넘어짐 수는 두 수를 더해 짐작할 수 없다. 올린 뒤 싸움 96 판을 한 번 재 둘 것.
- 두 팔 엇갈림 D 는 흔들기(판 시작에 물리 스텝 0 ~ 7 번 더 쉬기)를 해도 값이 한 자리도 안 바뀌었다. 정한 손가락 길이라 씨앗 · 시작 흔들림에 안 바뀌는 장면이다. 그래서 8 판 모두 같은 수다.
