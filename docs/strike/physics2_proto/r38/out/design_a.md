## 0. 결과 먼저
1. **자료의 버팀은 엔진이 미는 힘보다 한 자릿수 작다.** 살갗 10 ~ 26 N · 살은 '그보다 작음' · 연골 · 뼈 70 ~ 140 N [읽은] 대 레이피어 런지 닿음 뒤 미는 힘 최대 가운데 306 ~ 724 N [잰 nf]. → A 로 지으면 **깊이는 버팀이 아니라 공격자가 얼마나 더 다가오느냐(몸의 움직임 · 코등이)가 정한다.** 버팀 값은 '뚫리나'만 정하고 '얼마나'는 거의 안 정한다.
2. 그래서 A 는 찌르기를 크게 세게 만든다: 칼끝이 축으로 닿은 묶음 거의 모두가 뚫린다(레이피어 런지 +0.45 L1 46 / 47 · L2 37 / 38 — 오늘 ① 상처 0 · 1) [잰 nf · 부딪힘 일 ≥ 살갗 일 0.2 J 로 셈]. 깊이 어림(닿는 빠르기 × 미는 시간) 가운데 레이피어 런지 18 ~ 20 cm · 가까운 찌르기 7 ~ 15 cm · 싸움 4 ~ 9 cm [어림].
3. 구조: Rapier JS 0.19.3 에는 닿음을 무르게 고치는 걸이(modifySolverContacts)가 없다(filterContactPair 만) [읽은 physics_hooks.d.ts]. → **칼끝 · 몸 쌍은 엔진 닿음을 끄고(0) 버팀을 판정 코드가 안 힘 쌍으로 건다** — 지금 '끌림' 자리(combat.js 529–616)를 갈음. 갈음되는 것은 '에너지 예측(predict → pass)'이고, 남는 예측은 **기하(칼끝이 축으로 들어오나)뿐**.
4. 숨은 도움 없음: 버팀은 칼 · 몸 토막에 같은 점 · 반대 방향(운동량 · 각운동량 보존) · 한 스텝 충격량이 상대 빠르기를 못 뒤집게 상한(지금 Jcap 꼴) → 에너지를 만들지 않는다. 살갗 천막만 탄성(저장 ≤ ½·20 N·0.02 m = 0.2 J [어림]) [읽은 코드 600–609 꼴].
5. 사장님 몫이 셋: ① 옷 · 누비옷을 무엇으로 둘지(누비옷 50 J [2차 인용] 이면 게임 찌르기 거의 다 막힘 · 옷 한 겹 ×1.1 ~ 1.5 면 거의 다 뚫림) ② 깊이 → 상처 곡선의 깊이(자료 없음) ③ 배율들(0.8 · 1.3 · 2.0 · 2.5)을 상처에만 걸지 버릴지. 이 셋이 정해지기 전에는 균형 값이 없다.

### 스텝마다의 셈 (pierce 하나)
1. 들어올 때 적음(부위 몸 좌표): 들어온 점 E · 들어온 방향 u(칼 축) · 지난 끝 길이 L_exit(E 에서 u 로 콜라이더를 쏜 길이 — castRay).
2. 매 스텝: 칼끝을 부위 좌표로 → 깊이 d = (T − E)·u · 옆 어긋남 e. 상대 빠르기 v = v칼(T) − v부위(T) · 축 몫 s = v·u · 옆 몫 v_l.
3. 유효 질량 μ = 1 / (1/m칼손(T,u) + 1/m부위(T,u)) — 지금 gripMass · bodyMass 그대로.
4. 천막(d < XP): 충격량 J = (K·d + C·s)·dt · K = FP·옷/XP · C 는 임계 감쇠 2√(K·μ) · 감쇠 몫은 ≤ μ·|s|. d ≥ XP → **뚫림**(strike).
5. 뚫린 뒤: s > 0 이면 J = min(R(d)·dt, μ·s) (R = FF + 뼈 겹 · 옷은 천막에서 이미 셈) · s < 0 이면 J = −min(F_out·dt, μ·|s|). 옆: J_l = min(F_side·dt, μ_l·|v_l|) 반대쪽. 일 W += J·s (흩어진 에너지 — 아픔 · 균형 · 판 닳음의 E 로).
6. 칼에 −J · 부위에 +J 를 같은 점 T(칼 중심선 위)에 — 지금 600–609 와 같은 꼴.
7. 끝: d ≤ 0(빠짐) → 지움 · d > L_exit(꿰뚫음) → 두 겉 사이만 FF · 코등이 · 손잡이는 칼날이 아니므로 엔진이 굳게 막음(걸이 226) → 자연스러운 끝.
- 튐: 천막 K = 1000 N/m [어림 20 N ÷ 0.02 m] · μ 최소 0.11 kg(레이피어 mFree 10 % [잰 codemap]) → ω·dt = 0.79 < 2(반암시 적분 안정) [어림]. 뚫린 뒤는 마찰꼴 + 뒤집지 않는 상한 → 튈 거리 없음. 걸이 뒤 afterStep 에서 거므로 한 스텝 늦음(2 m/s 에서 1.7 cm 지나침 [어림]) — 지금 끌림과 같은 늦음.

## 4. 정직
- 몸 밖 힘 · 자리 · 빠르기 쓰기 없음: 버팀 J 는 칼 · 부위에 짝(같은 점 · 반대) — Σp · ΣL 보존. 뚫린 뒤 J 는 상대 빠르기의 반대 · ≤ μ|s| 라 운동 에너지를 줄이기만 함. 천막 탄성은 저장한 만큼만 돌려줌(≤ 0.2 J).
- 엔진 충격량을 읽지 않는다 → r36 의 교정 6/7 · 창 문제를 안 탐.
- 스위치 없음: 칼끝 문은 기하 조건이지 켜고 끄는 값이 아님. 사람 · AI 같은 길(combat 은 싸움꾼을 안 가름 · AI 찌르기도 skill.thrust → 같은 몸) · 무기 이름으로 가르지 않음(칼끝 무딤은 칼 값으로).
- 관절 토크는 안 건드림 — 깊이는 몸이 사람 한도 안에서 낸 힘의 결과.
- 흠: 배율(0.8 · 레이피어 1.3 · energyScale 2.0 · FINISH 2.5)은 물리 셈에 자리가 없다 — 깊이에 곱하면 숨은 도움이 됨 → **상처 심각도에만** 걸거나 버림(사장님 몫).

## 6. 위험과 모르는 것 · 틀렸다면 어디서
- **깊이를 정하는 것이 자료가 아니라 몸의 움직임**이다. 팔이 물러(r36) 손이 칼을 안 밀면 깊이가 얕고, 런지 몸이 멎지 않으면 꿰뚫음이 흔해짐 — 어느 쪽인지 시뮬 전에는 모름. 드러나는 곳: 첫 판의 깊이 분포가 §3 어림의 0.5 ~ 2 배 밖.
- 상처를 깊이로 바꾸는 D_zone 이 자료 없음 → 이것으로 옛 균형에 맞추면 '값으로 덮기'. 장기 깊이 자료(부위별)를 먼저 찾아야.
- 거의 모든 칼끝 닿음이 뚫리면 싸움이 짧아지고 찌르기가 이긴다 — 현실엔 가깝지만 게임 균형은 크게 흔들림. 누비옷 값 하나가 이를 거꾸로 뒤집음(다 막힘).
- 뼈 · 갈비 자리 모형이 없음 · 칼 휨은 굳은 칼로 못 그림 · 옆으로 움직인 칼은 몸 안에서 '벤 것'인데 지금 상처 식이 없음.
- 사람 탭이 뚫리는 순간 landed 로 거두면(skill.js 461 · 468) 깊이가 탭 거둠 시간에 묶임 — 사람 · AI 같은 길이지만 느낌을 정하는 자리. 첫 판은 그대로 두고 잰 뒤 여쭘.
- 걸이가 기하를 스텝 전 값으로 봄 → 빠른 칼끝이 한 스텝에 겉을 넘으면 문이 늦어 엔진이 먼저 부딪힘(부딪힘 몫만 잃음 — §1).
