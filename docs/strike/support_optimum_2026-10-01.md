## 9. 남은 질문

1. **가슴 앞섬 0 점 (모든 칸)**: 게임 가슴 최고가 칼끝 −190~−200 ms (띠 −70~−25). 골반 앞섬도 ≈ 0 점. 받침 손잡이로는 못 고침 → R2′ (다리 → 골반 먼저 → 척추 탄성 → 팔) 몫.
2. **받침 0.3 이 남긴 발 하중**: 서기 발 하중 p10 0.77 BW (띠 0.95~1.05, 0 점), 걷기 p10 ≈ 0 (measure 걷기 판, 0 점) — 20 칸 모두. 사장님 상자 (0.1~0.3) 안에서는 척도가 못 가름.
3. **human 다리에서 밀치기 미발사** (11/40 판): 밀치는 쪽 다가가기·거리 원인 안 캠. 확인표 85·86 은 '사장님 확인 전' 그대로.
4. **소음 바닥이 반쪽**: 베기·서기·걷기는 seed 무관 한 궤적 → 그 장면 소음 안 잼. 패드 흔들림 seed 를 주는 판이 있으면 더 좁게 가를 수 있음.
5. 'on' 과 'fall' 은 소음 안 동점 (a0.3: 58.5 vs 57.5). 사장님 손맛으로 'fall' 을 고르셔도 유사도로는 같음.
