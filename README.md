# 검투사 프로토타입 (halfsword)

〈하프 소드〉에서 영감을 받은 **물리 기반 중세 결투 게임**을 만들어 보는 첫 게임 프로젝트예요.
스마트폰 브라우저에서 바로 플레이할 수 있게 만들고 있어요.

- 몸은 관절로 이어진 **액티브 래그돌**이에요. 애니메이션 없이 "근육 힘"으로 서고, 걷고, 버텨요.
- 카메라는 원작처럼 **내 캐릭터 어깨 너머(3인칭)**에서 상대를 바라봐요. 원형 경기장을 자유롭게 돌며 싸워요.
- 칼은 **손가락으로 끌어서** 직접 휘둘러요. 좌우로 끌면 가로베기, 위아래로 끌면 내려치기. 빠르게 휘둘러야 세게 들어가요.
- 폰에서는 **왼쪽 아래 조이스틱**으로 걸어요. (설정에서 "기울기" 이동으로 바꿀 수도 있어요.) 몸은 항상 상대를 향해 돌아요.
- **체력 게이지가 없어요.** 칼이 닿은 순간의 에너지로 베기·찌르기·타박을 가려 상처를 내요.
  목이나 머리에 제대로 들어가면 한 방에 끝나고, 얕은 상처는 피를 흘리며 서서히 약해져요.
- 무게중심이 발 밖으로 밀려나면 비틀거리며 발을 딛고, 못 버티면 넘어져요.
- 크게 다치면 **부상**이 몸에 남아요: 절뚝거림, 늘어진 팔, 웅크린 몸, 멍한 비틀거림, 창백한 얼굴.
  넘어지면 무릎을 꿇었다가 일어나고, 다리를 크게 다치면 무릎 꿇은 채로 싸워요.
- 칼이 지나간 자리엔 **옷이 찢어지고**, 피가 옷에 번지고, 투구는 긁히고 찌그러지다 벗겨져 날아가요. 칼날에도 피가 묻어요.

## 조작법

| | 스마트폰 (가로) | PC |
|---|---|---|
| 칼 휘두르기 | 화면을 손가락으로 끌기 | 화면 클릭(마우스 잠금) 후 마우스 이동 |
| 걷기 (전후좌우) | 왼쪽 아래 조이스틱 | W A S D 또는 방향키 |
| 기울기 영점 | ◎ 버튼 | - |
| 일시정지 | Ⅱ 버튼 | P |

설정의 **이동 방식**을 "기울기"로 바꾸면 폰 윗부분을 앞/뒤로 기울여 전진·후퇴, 운전대처럼 돌려 옆걸음해요.
이때 ◎ 버튼을 누르면 **지금 폰을 든 각도**가 "가만히 서 있기"의 기준이 돼요.

## 실행하기

Node.js 20 이상이 필요해요.

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버 실행 → 터미널에 나오는 주소를 브라우저로 열기
npm run build    # 배포용 파일을 dist/ 에 만들기
```

`npm run dev` 를 하면 `Network:` 주소도 나와요. 같은 와이파이에 있는 폰에서 그 주소를 열면 폰으로도 볼 수 있어요.
다만 **기울기 센서는 https 주소에서만** 동작해서, 이 방법으로는 조이스틱으로 움직이게 돼요.
기울기까지 폰으로 제대로 테스트하려면 아래 GitHub Pages 배포를 쓰세요.

### 폰에서 플레이하기 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages → Source** 를 **GitHub Actions** 로 바꿔요 (처음 한 번만).
2. `main` 브랜치에 코드가 올라가면 자동으로 배포돼요 (`.github/workflows/deploy.yml`).
3. `https://<아이디>.github.io/halfsword/` 를 폰에서 열어요.

## 코드 구조

```
index.html        화면 틀, 메뉴, 부상 화면 효과 (HTML/CSS)
src/
  config.js       ★ 밸런스/조작감/카메라 숫자 모음. 튜닝은 여기서부터!
  looks.js        검투사 겉모습 (옷 색, 투구, 머리카락)
  main.js         게임 본체: 화면·물리 세계 준비, 게임 루프, 타격 판정, UI
  fighter.js      검투사 = 액티브 래그돌 (몸, 관절 근육, 균형, 칼 조종)
  ai.js           상대 AI (플레이어와 같은 방식으로 손/이동만 조종)
  input.js        터치 드래그, 마우스, 키보드, 기울기 센서
  combat.js       타격 분석 (베기/찌르기/타박, 에너지, 칼이 살을 가르고 지나가기)
  arena.js        중세 마상시합장 배경 (관중석, 관중, 깃발, 울타리, 소품)
  effects.js      피/불꽃 입자, 효과음(코드로 합성), 상처 데칼
```

사용한 도구:
- [Three.js](https://threejs.org/): 3D 그래픽
- [Rapier](https://rapier.rs/): 물리 엔진 (강체, 관절, 충돌)
- [Vite](https://vite.dev/): 개발 서버, 빌드

### 핵심 원리 (fighter.js)

1. **몸 (해부학)**: 골반·배·가슴·머리, 위팔·아래팔, 허벅지·정강이·발 15조각. 길이와 무게는 생체역학 표준표(Winter)의
   체중 75kg 성인 비율을 따랐어요 (가슴 16kg, 허벅지 7.5kg, 머리 6kg …).
   무릎·팔꿈치·발목은 한 방향으로만 굽는 **경첩 관절**, 허리·목·어깨·엉덩이는 구형 관절이고,
   모든 관절에 사람이 실제로 굽힐 수 있는 **가동 범위**를 걸었어요 (무릎은 뒤로 안 꺾임).
2. **근육**: 각 관절에 물리 엔진의 **관절 모터**를 달아 목표 자세로 돌아가게 해요.
   관절마다 **낼 수 있는 최대 힘(N·m)** 이 있어서 (무릎 250, 엉덩이 280, 어깨 110, 목 40 …)
   무거운 칼이나 충격은 근육이 다 버티지 못하고 밀려요. 다친 부위는 그만큼 힘이 빠져요.
   (참고: Rapier의 관절 모터는 오차를 반각의 사인으로 재서 실제 힘이 절반이에요. 그래서 강도를 ×2로 넘겨요.)
   처음엔 회전력을 직접 계산했는데, 가느다란 팔다리를 길이 방향으로 비트는 축은 관성이 아주 작아서
   1/120초 계산이 매번 목표를 지나쳐 다리가 프로펠러처럼 돌았어요. 관절 모터는 엔진이 충돌·관절과
   함께 한꺼번에 풀기 때문에 아무리 세게 해도 떨리지 않아요.
3. **균형**: 다리 근육이 "골반은 위로" 밀어 몸을 받쳐요. **딛고 있는 발이 있을 때만** 받칠 수 있어서, 두 발이 뜨면 주저앉아요.
   몸을 세우는 힘은 출렁이지 않도록 감쇠비 ≈ 1(딱 멈추는 값)로 맞췄고, 가속할 때는 그만큼 앞으로 숙여요.
   앞으로 미는 힘은 골반과 상체에 무게 비율대로 나눠 줘요(골반만 밀면 상체가 뒤로 젖혀져 마리오네트처럼 보여요).
4. **걷기**: 다리 흔드는 속도를 **실제로 이동한 거리**에 묶었어요. 한 주기의 60%는 발을 딛고(몸이 가는 만큼 발이 뒤로),
   40%는 무릎을 들어 앞으로 가져와요. 다리는 실제 이동 방향(앞/뒤/옆/대각선)으로 흔들고, 딛는 다리가 기울어진 만큼
   골반을 낮춰 발이 땅에 닿게 해요.
   너무 기울거나 균형 게이지가 바닥나면 근육 힘을 빼서 래그돌로 쓰러뜨려요.
5. **칼과 팔 (IK)**: 칼은 아래팔 끝 손목에 관절로 붙어 있어요. 손 목표는 가슴 앞 평면의 (좌우, 위아래) 점이고,
   가운데로 모을수록 팔을 앞으로 뻗어요. 예전처럼 손을 줄로 끌어당기지 않고, **역운동학(IK)** 으로
   "손이 거기 가려면 어깨와 팔꿈치가 몇 도여야 하나"를 풀어서 **어깨·팔꿈치 근육**이 그 각도로 당겨요.
   그래서 칼 무게는 팔 근육이 버티고, 반작용은 어깨를 통해 몸통으로 자연스럽게 전해져요.
   손목 힘은 칼끝 방향과 칼날 각도만 맞춰요.
6. **타격 (combat.js)**: 칼이 몸에 닿는 순간을 분석해요.
   - 닿은 점에서 칼과 몸의 **속도 차이**를 구하고, 운동 에너지 = ½ × 유효질량 × 속도² (J)를 계산해요.
   - **날이 앞장서면 베기**, 칼끝으로 곧게 들어가면 **찌르기**, 칼 면이나 손잡이면 **타박**이에요.
   - 부위마다 "살을 가르기 시작하는 에너지"와 "완전히 통과하는 에너지"가 달라요 (`ANATOMY`). 투구는 머리 윗부분을 막아줘요.
   - 에너지가 충분하면 물리 엔진의 **충돌 훅**으로 튕겨내는 힘을 끄고, 칼이 **살을 가르며 지나가게** 해요.
     몸이 흡수한 에너지만큼 칼이 느려지고, 그 운동량이 몸에 전달돼요. 모자라면 칼이 박히거나 튕겨요.
7. **몸 상태**: 피(양·출혈), 의식, 통증, 팔다리 기능을 따로 계산해요 (`VITALS`).
   목 베임·머리 치명상은 즉사, 피가 45% 아래면 쓰러지고, 머리를 세게 맞으면 기절, 칼 든 팔을 크게 다치면 칼을 놓쳐요.
8. **균형 (fighter.js `updateFooting`)**: 무게중심과 그 속도로 "캡처 포인트"(멈추려면 발을 디뎌야 할 곳)를 구해요.
   그 점이 발 밖으로 나가면 자동으로 그쪽으로 발을 딛고, 너무 멀면 몸을 세우는 힘이 빠지면서 실제로 넘어져요.
9. **타격감**: 에너지에 비례한 멈칫, 재질별 소리(베기/찌르기/타박/뼈/쇳소리), 휘두르는 바람 소리, 결정타 슬로모션.
   카메라는 "스프링에 매단 카메라"라서 충격 방향으로 밀렸다가 부드럽게 돌아오고, 발을 디딜 때 살짝 내려앉아요.
10. **흔적(데칼)**: 상처·찢김·번지는 핏자국·멍·투구 긁힘을 몸 표면에 투사해서 붙여요 (`effects.js`의 `stickDecal`).
    옷이 찢어진 곳, 찌그러진 투구는 다음 타격을 덜 막아줘요.
11. **진동**: 안드로이드는 표준 진동. 아이폰 사파리는 손가락을 누르거나 뗀 순간에만 진동을 허락해서,
    맞히면 예약해 두었다가 **손가락을 뗄 때** 울려요 (실험). 제대로 된 진동은 앱으로 감싸야 가능해요.

### 튜닝 팁

`src/config.js` 의 숫자를 바꾸고 저장하면 개발 서버가 바로 새로고침해 줘요.

- 너무 쉽게 죽는다 / 안 죽는다 → `ANATOMY`의 `cut`, `stab` 값 (클수록 질김)
- 칼이 너무 가볍다 → `WEAPON.mass` ↑, `WEAPON.aimStiffness` ↓ (칼이 관성대로 더 따라옴)
- 휘두르는 게 너무 느리다 → `WEAPON.maxAimTorque` ↑, 팔 근육 힘은 `fighter.js`의 `jointDefs`(k, max)
- 너무 잘 넘어진다 → `BALANCE.fallRange` ↑, `VITALS.staggerPerJoule` ↓
- 상대가 너무 세다/약하다 → `AI_LEVELS`
- 폰 조작 감도 → `INPUT.touchSensitivity`, `INPUT.tiltFullDeg`
- 걸음 보폭 / 걷는 속도 / 몸 돌리는 속도 → `BODY.stepLength`, `BODY.moveSpeed`, `BODY.turnSpeed`
- 몸이 휘청이는 정도 → `BODY.uprightStiffness`, `BODY.uprightDamping` (감쇠를 줄이면 출렁인다)
- 시작 간격 → `ARENA.startGap`, 경기장 크기 → `ARENA.radius`
- 카메라 거리/높이/어깨 위치 → `CAMERA`
- 옷 색, 투구 바꾸기 → `src/looks.js`

브라우저 개발자 도구 콘솔에서 `game.config.WEAPON.mass = 3` 처럼 실행 중에 바꿔볼 수도 있어요.
