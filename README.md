# 검투사 프로토타입 (halfsword)

〈하프 소드〉에서 영감을 받은 **물리 기반 중세 결투 게임**을 만들어 보는 첫 게임 프로젝트예요.
스마트폰 브라우저에서 바로 플레이할 수 있게 만들고 있어요.

- 몸은 관절로 이어진 **액티브 래그돌**이에요. 애니메이션 없이 "근육 힘"으로 서고, 걷고, 버텨요.
- 카메라는 원작처럼 **내 캐릭터 어깨 너머(3인칭)**에서 상대를 바라봐요. 원형 경기장을 자유롭게 돌며 싸워요.
- 칼은 **손가락으로 끌어서** 직접 휘둘러요. 좌우로 끌면 가로베기, 위아래로 끌면 내려치기. 빠르게 휘둘러야 세게 들어가요.
- **폰을 앞뒤로 기울이면** 전진·후퇴, **좌우로 기울이면** 옆걸음이에요. 몸은 항상 상대를 향해 돌아요.
- 맞으면 비틀거리고, 균형을 잃으면 쓰러졌다가 다시 일어나요.

## 조작법

| | 스마트폰 (가로) | PC |
|---|---|---|
| 칼 휘두르기 | 화면을 손가락으로 끌기 | 화면 클릭(마우스 잠금) 후 마우스 이동 |
| 전진 / 후퇴 | 폰 윗부분을 앞으로 / 뒤로 기울이기 | W / S 또는 ↑ / ↓ |
| 옆걸음 | 폰을 운전대처럼 좌우로 돌리기 | A / D 또는 ← / → |
| 기울기 영점 | ◎ 버튼 | - |
| 일시정지 | Ⅱ 버튼 | P |

기울기 센서를 쓸 수 없는 환경이면 화면 왼쪽 아래에 조이스틱이 자동으로 나타나요.
◎ 버튼을 누르면 **지금 폰을 든 각도**가 "가만히 서 있기"의 기준이 돼요.

## 실행하기

Node.js 20 이상이 필요해요.

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버 실행 → 터미널에 나오는 주소를 브라우저로 열기
npm run build    # 배포용 파일을 dist/ 에 만들기
```

`npm run dev` 를 하면 `Network:` 주소도 나와요. 같은 와이파이에 있는 폰에서 그 주소를 열면 폰으로도 볼 수 있어요.
다만 **기울기 센서는 https 주소에서만** 동작해서, 이 방법으로는 조이스틱으로 움직이게 돼요.
기울기까지 폰으로 제대로 테스트하려면 아래 GitHub Pages 배포를 쓰세요.

### 폰에서 플레이하기 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages → Source** 를 **GitHub Actions** 로 바꿔요 (처음 한 번만).
2. `main` 브랜치에 코드가 올라가면 자동으로 배포돼요 (`.github/workflows/deploy.yml`).
3. `https://<아이디>.github.io/halfsword/` 를 폰에서 열어요.

## 코드 구조

```
index.html        화면 틀, 메뉴, 체력바 (HTML/CSS)
src/
  config.js       ★ 밸런스/조작감/카메라 숫자 모음. 튜닝은 여기서부터!
  looks.js        검투사 겉모습 (옷 색, 투구, 머리카락)
  main.js         게임 본체: 화면·물리 세계 준비, 게임 루프, 타격 판정, UI
  fighter.js      검투사 = 액티브 래그돌 (몸, 관절 근육, 균형, 칼 조종)
  ai.js           상대 AI (플레이어와 같은 방식으로 손/이동만 조종)
  input.js        터치 드래그, 마우스, 키보드, 기울기 센서
  effects.js      피/불꽃 입자, 효과음(코드로 합성)
```

사용한 도구:
- [Three.js](https://threejs.org/): 3D 그래픽
- [Rapier](https://rapier.rs/): 물리 엔진 (강체, 관절, 충돌)
- [Vite](https://vite.dev/): 개발 서버, 빌드

### 핵심 원리 (fighter.js)

1. **몸**: 골반, 가슴, 머리, 팔 4개, 다리 4개를 구형 관절로 연결했어요.
2. **근육**: 매 물리 스텝(1/120초)마다 각 관절에 "목표 자세로 돌아가려는 회전력"(PD 제어)을 걸어요.
3. **균형**: 골반을 보이지 않는 스프링으로 떠받치고, 몸통을 똑바로 세우는 회전력을 걸어요.
   너무 기울거나 균형 게이지가 바닥나면 근육 힘을 빼서 래그돌로 쓰러뜨려요.
4. **칼**: 손목에 관절로 붙어 있어요. 손 목표는 가슴 앞 평면의 (좌우, 위아래) 점이고, 가운데로 모을수록 팔을 앞으로 뻗어요.
   칼자루를 그 점으로 끌어당기는 힘과, 칼끝을 원하는 방향으로 돌리는 힘을 걸어요.
   이때 반작용이 몸통에 걸려서, 세게 휘두르면 몸도 끌려가요.
5. **피해**: 칼이 몸에 닿는 순간 **칼날의 그 지점 속도**로 피해를 계산해요. 부위(머리 1.8배 등)와 찌르기 보너스가 붙어요.

### 튜닝 팁

`src/config.js` 의 숫자를 바꾸고 저장하면 개발 서버가 바로 새로고침해 줘요.

- 칼이 너무 가볍다 → `WEAPON.maxHandForce` ↓, `WEAPON.mass` ↑
- 휘두르는 게 너무 느리다 → `WEAPON.maxHandSpeed` ↑, `WEAPON.maxAimTorque` ↑
- 너무 잘 넘어진다 → `BODY.fallTiltDeg` ↑, `DAMAGE.balanceLossPerDamage` ↓
- 상대가 너무 세다/약하다 → `AI_LEVELS`
- 폰 조작 감도 → `INPUT.touchSensitivity`, `INPUT.tiltFullDeg`
- 카메라 거리/높이/어깨 위치 → `CAMERA`
- 옷 색, 투구 바꾸기 → `src/looks.js`

브라우저 개발자 도구 콘솔에서 `game.config.WEAPON.mass = 3` 처럼 실행 중에 바꿔볼 수도 있어요.

- [x] **2단계: 승패.** 부위별 피해, 체력·균형 게이지, 승리/패배 화면

- [x] **3.5단계: 원작 시점.** 어깨 너머 3인칭 카메라, 원형 경기장 자유 이동, 누비 상의·케틀햇 등 외형
- [ ] **4단계: 손맛 다듬기.** 실제 폰 플레이 피드백으로 무게감·감도·AI 튜닝
- [ ] **5단계: 픽셀아트 스타일.** 지금의 "픽셀 모드(실험)"를 발전시켜 색 줄이기, 외곽선, 도트 텍스처
- [ ] **6단계: 콘텐츠.** 무기 종류(도끼, 메이스, 창), 갑옷(부위별 방어), 여러 상대 연속 대결
- [ ] **7단계: 2인 대전.** 폰 한 대 반반 나눠쓰기 → (먼 훗날) 온라인
